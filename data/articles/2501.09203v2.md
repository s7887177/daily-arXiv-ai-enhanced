# 橋樑與隧道的裂縫怎麼量？這套系統把 AI 視覺、雷射雷達、慣性感測器接起來，直接給出毫米級的 3D 裂縫地圖

> 原始論文：3D Modeling and Automated Measurement of Concrete Cracks via Segment Anything Refinement and Visual Inertial LiDAR Fusion
> 作者·單位：Pengru Deng、Jiapeng Yao、Chun Li、Su Wang、Xinrun Li、Varun Ojha、Xuhui He（中南大學土木工程學院、湖南省軌道交通工程結構災防重點實驗室、Carizon、NVIDIA、英國 Newcastle University）
> arXiv：2501.09203v2 ・ 分類：cs.CV／cs.RO

一句話說重點：橋樑、隧道老化後最早冒出來的警訊是混凝土裂縫，但用相機拍照測量裂縫的傳統做法有兩個痛點——AI 換到沒看過的新場景就不準、且只能在 2D 影像上量寬度卻不知道裂縫真正在 3D 空間哪裡。這篇把通用視覺模型 SAM、雷射雷達 SLAM、慣性感測器接起來，做出能在任何水泥結構上「自動圈出裂縫＋重建 3D 模型＋量出毫米級寬度與空間位置」的一體化系統。

---

## 背景：基礎建設老化，裂縫檢測卡在兩個痛點

橋樑、隧道、水壩這些長期承載的混凝土結構，會因為負載累積、環境腐蝕產生表面裂縫。裂縫的**寬度、數量、空間分佈與走向**是評估結構安全的關鍵指標——裂縫變寬代表強度衰減，走向能判斷是結構性損傷還是表面性問題。

人工巡檢有三個缺陷：**不一致、主觀、不能上樓爬高**。自動化裂縫檢測因此成為熱門研究方向，但目前的方法都各有侷限：

1. **任務專屬 CNN**（卷積神經網路）：在固定資料集上訓練，**換到沒見過的場景就崩潰**（不同的水泥色澤、紋理、光照、髒污都能讓 AI 失準）。實務上工程師每換一個橋就要重新標註、重新訓練，**根本不實際**。
2. **基礎模型如 SAM**（Segment Anything Model，Meta 的萬物分割模型）：泛化能力強，但**極度依賴 prompt 品質**。簡單的影像處理算出來的 prompt 常把噪點、髒污、非混凝土區塊也誤啟動，造成裂縫圈得不準。
3. **3D 重建技術**：
   - **單張相機**：只能在平面假設下測寬度，**沒有真實 3D 位置**。
   - **SfM（Structure-from-Motion）+ 無人機攝影**：幾何精度通常只到公分級，**毫米級的裂縫量不到**。需要影像高度重疊、軌跡規劃精確、不能即時。
   - **視覺 SLAM**：能定位但精度有限，且**特徵點為主，細節容易遺失**。
   - **多模態 SLAM**：幾何精度好，但**語意（哪些點屬於裂縫）邊界模糊**。

要解決的核心痛點是：能不能做出一個**「不用重訓 + 高泛化的裂縫分割」＋「毫米級精度的 3D 定位與量測」**的整合系統，並且全程自動，不用人工後處理？

## 怎麼做：兩個階段把 SAM 與多感測器 SLAM 接起來

作者提出的系統有兩個主要階段，總覽見下圖：

![論文 Figure 1：系統流程總覽。上半「裂縫識別」階段：先用一個小型基礎分割模型對影像產生初步裂縫遮罩，再透過 SAM 精修（這是論文的核心貢獻），輸出乾淨的裂縫 Mask。下半「裂縫量測」階段：多感測器（相機、LiDAR、IMU）先校準，跑 LiDAR-SLAM 重建出 3D 結構點雲，再用「多幀多模態融合」把上半的裂縫 Mask 對齊到 3D 點雲上，最後自動量測幾何特性（寬度、位置、走向等）。深色方塊是論文的核心貢獻；橢圓是資料元素；白色方塊是支援步驟。](assets/articles/2501.09203v2-fig1.webp)

### 階段一：把 SAM 變成可靠的裂縫分割器

SAM 原本是個萬物分割模型，給它一個 prompt（點、框、文字）它就會圈出指定物件。問題是裂縫場景的 prompt 不好做：用簡單影像處理算出的 prompt 會被髒污、標記、非混凝土物件干擾。作者的方法是「**雙模型協作**」：

1. 先用一個**小型專用裂縫偵測模型**對影像跑「基本分割」，給出粗略的裂縫位置。
2. 把這個粗略結果**轉成 SAM 的高品質 prompt**——具體做法是設計一個取樣演算法，從粗略的裂縫遮罩中**抽取骨架點（skeletal points）**當 SAM 的點 prompt。骨架點落在裂縫中央線上，比邊界點穩定得多。
3. 用 SAM 對這些 prompt 做精修，得到 pixel-level 的裂縫遮罩。
4. 額外加一個「**分割品質評估模組**」，自動判斷 SAM 的輸出是否可靠，不可靠的就丟回前一步重做。

這個設計的關鍵是：小模型負責「找裂縫在哪」，大模型 SAM 負責「圈得精準」。小模型即使在新場景表現一般，只要能粗略指出「這附近有裂縫」，SAM 就能補上精度——**等於把泛化問題從「全程要重訓」降階成「prompt 提示就好」**。

### 階段二：用 LiDAR SLAM 把 2D 裂縫遮罩搬到 3D

第二階段的核心是「Visual Inertial LiDAR（VIL）SLAM 融合」——同步整合三種感測器：

- **相機（RGB 影像）**：提供裂縫的語意資訊（哪些像素屬於裂縫）。
- **LiDAR（Light Detection and Ranging，雷射雷達）**：提供高精度 3D 幾何（點雲距離精度可到毫米級）。
- **IMU（Inertial Measurement Unit，慣性測量單元）**：提供裝置在掃描過程中的運動軌跡，補上相機與 LiDAR 之間的時間同步與運動補償。

三者融合後的 SLAM 流程能輸出一張**「彩色 + 帶語意的高密度 3D 點雲」**——也就是每個點不只有 XYZ 座標，還標註了「這是不是裂縫」。多幀融合的好處是不同視角的同一條裂縫能彼此驗證，**消除單張影像中視角偏差造成的寬度誤差**。

### 階段三：自動量測

從帶語意的 3D 點雲直接抽出裂縫的：
- **寬度**：直接在 3D 點雲上量「裂縫邊界兩點的真實 3D 距離」（**不是 2D 影像上的像素數**），自動排除非平面結構帶來的視角扭曲。
- **空間位置**：每段裂縫都對應到結構物上的真實 3D 座標。
- **長度、走向**：沿 3D 骨架線追蹤。

這一段完全自動，不用人工後處理——這在工程實務上是個大進步，因為傳統 3D 重建後常常還要人工標記、量測、轉檔。

## 結果：泛化精度提升 6%，寬度誤差 < 0.1 毫米

作者在多個真實混凝土結構上做實驗，主要發現：

1. **裂縫分割**：對沒看過的新場景，IoU（Intersection over Union，交集除以聯集，分割品質的標準指標）**比現有任務專屬模型高 6%**。在複雜場景（有髒污、標記、雜物）下表現特別穩定。
2. **3D 寬度量測**：在真實混凝土上的**平均寬度估計誤差低於 0.1 毫米**——這已經達到結構安全評估所要求的等級。
3. **同步 3D 寬度與位置**：論文用一張比較表列出，**這是第一個同時支援「非平面結構 + 3D 位置與寬度同步 + 自動量測」三項能力的方法**。傳統 SfM 方法或單幀融合方法都最多滿足其中兩項。

## 做不到 / 沒解決的地方

1. **硬體門檻不低**：需要相機 + LiDAR + IMU 同步校準的裝備，**比手機拍照貴得多**。實務上可能整合在工程巡檢機器人或無人機上。
2. **環境條件依賴**：LiDAR 在雨天、霧、強反光（玻璃、水面）下精度會掉；論文沒測這些極端條件。
3. **裂縫類型限制**：研究聚焦混凝土結構表面的可見裂縫，**對隱藏裂縫、內部裂縫、極細微髮絲裂縫（< 0.05 mm）能力未驗證**。鋼結構、磚石結構的可移植性沒測。
4. **計算需求**：多模態 SLAM 與 SAM 都是重模型，**真實在工地端的即時性能未量化**——論文沒給單張處理時間或裝置上的延遲。
5. **依賴底層小模型**：第一階段需要一個「基本裂縫偵測模型」做粗略提示，**這個模型在極度陌生場景仍可能失準**——SAM 無法從零開始找裂縫。
6. **平移到大型結構的可擴展性**：實驗看似是局部結構（橋面、牆面），**對整座橋、整段隧道的全域 SLAM 累積誤差未深入討論**。
7. **語意類別只到「裂縫 / 非裂縫」**：實際工程還想分「結構性 / 非結構性」「應力裂縫 / 收縮裂縫」等，這套系統只給出存在性，不分類型。

## 怎麼看這件事

**為什麼值得在意？** 全球老化的基礎建設是個千億級的問題——美國、歐洲、日本、中國都有大量服役 30 年以上的橋樑與隧道需要例行檢測，但人工巡檢成本高、不一致、危險（要爬高）。「**自動化 + 機器人化 + 毫米級精度**」是這個產業必然的方向。本篇把通用 AI 視覺（SAM）和工程級感測器（LiDAR + IMU）有機結合，並把整個流程做到「**從原始感測資料一路自動到結構工程師可直接讀的 3D 損傷地圖**」——這比過去任何單點突破都更接近實用化。

**哪裡該保留懷疑？** 「寬度誤差 < 0.1 mm」聽起來很厲害，但這需要**特定的感測器組合與校準品質**——對未來工地實際的可移植性（雨天、震動、暗光、不同混凝土材質）論文沒充分驗證。**6% IoU 提升**對學術算大進步，但「換到全新場景」這個敘事比較依賴實驗設計的選擇——選對基準（與一個明顯弱於 SAM 的小模型對打），數字當然好看。實際換到下一座橋是否仍能保持，需要更多獨立第三方驗證。

**怎麼理解這個研究方向？** 這代表「**基礎模型 + 領域感測器融合**」的範式正在土木／製造／醫療等垂直工程領域開花。SAM 這類 vision foundation model 不是萬靈丹，但**搭配特定領域的小模型當「智慧 prompt」**，能繞過「換場景就要重訓」的傳統痛點。未來這個思路會擴散到其他結構檢測（橋樑鏽蝕、隧道滲漏）、製造缺陷、農作物病害等需要「**廣泛泛化 + 精細測量**」的場景。
