# AI 推理時哪一步出錯了？讓黑盒模型自我診斷的新方法

> 原始論文：Diagnosing Multi-step Reasoning Failures in Black-box LLMs via Stepwise Confidence Attribution
> 作者·單位：Xiaoou Liu、Tiejin Chen（亞利桑那州立大學）、Dengjia Zhang（約翰霍普金斯大學）、Yaqing Wang（普渡大學）、Lu Cheng（伊利諾大學芝加哥分校）、Hua Wei（亞利桑那州立大學）
> arXiv：2605.19228v1 ・ 分類：cs.CL、cs.AI、cs.LG

一句話說重點：不需要偷看模型內部，只靠生成的推理步驟文字，就能找出「鏈式思考（Chain-of-Thought）」中最容易出錯的那一步——這套叫 SCA（逐步信心歸因）的方法讓模型自我糾錯的成功率提升最多 13.5%。

---

## 問題在哪裡

現在的大型語言模型（LLM）愛用「一步一步推理」（Chain-of-Thought）的方式解題，最後答案卻常常錯——更麻煩的是，你不知道錯在哪一步。

傳統方法有兩條路：一是請人一步一步標記哪裡錯了（貴到無法擴展）；二是叫另一個模型來「評審」（容易跟著犯同樣的錯）。還有些方法需要讀取模型內部的機率值（token logits），但商業 API 根本不開放這個資料。

**本文的目標**：只用模型輸出的文字推理步驟，找出每一步的可信程度。

## 怎麼做

核心思路：**正確的推理路徑雖然寫法多樣，但在關鍵邏輯節點上會有共識；錯誤的步驟會從這個共識偏離。**

研究者利用「資訊瓶頸（Information Bottleneck, IB）」原理，設計了兩種方法：

**NIBS（非參數 IB）**：不建圖，直接比較一道題的多次正確解答，找出共同出現的語意步驟集合，作為「共識錨點」。測試中的推理步驟若與這個錨點吻合，得到高信心分；偏離的步驟得到低分。

**GIBS（圖版 IB）**：把每次推理表示成一張有向圖（問題節點相互連接），再訓練一個圖神經網路，學習找出最能預測正確性的子圖。這個子圖就是「哪些步驟最要緊」的可微分答案。

兩種方法都只需要已知正確答案的樣本（訓練時用），推理時完全靠黑盒模型輸出——不需要 logits，不需要模型權重。

信心分數不只用來診斷：研究者還讓模型在「信心最低的步驟」處重新作答，比只說「你的答案不對，請修改」多出 13.5% 的糾錯成功率。

## 結果

在三個標準基準測試上：
- **GSM8K**（小學數學）：GIBS 在 AUROC、ACC@80% 等指標上優於所有基準
- **MoreHopQA**（多跳問答，需串接多個事實）：GIBS 仍保持最佳
- **DeepSeek-R1-Distill-Qwen-32B**（更強的推理模型）：也適用，泛化性佳

定性觀察：在數學應用題中，當模型在計算中途做了錯誤運算（例如「6 個筆記本×$10 寫成 $60 而非 $60 乘以 3 個學生」），GIBS 能精準把信心分數壓低在那一步，而非整條推理鏈都給低分。

## 做不到的地方

- NIBS 和 GIBS 都需要一組「已知正確答案」的訓練樣本來建立共識錨點或訓練圖神經網路；真正的開放題（沒有客觀答案）目前無法適用
- GIBS 需要額外的圖神經網路訓練，部署成本高於 NIBS
- 實驗僅在數學推理與多跳問答上驗證；創意寫作、開放對話等更主觀任務的效果未知
- 「最低信心步驟」的重試策略雖然提升糾錯率，但仍未達到接近完美的正確率

## 圖解

左側（A）：LLM 針對同一道題多次回答，每次答案被解析成一個有向推理圖（節點是子問題，邊是依賴關係）。中間（B）：正確解答的圖聚合出「共識錨點」（MCS，黃色節點），錯誤解答因為偏離這個結構而被標記。右側（C）：GIBS 用圖神經網路 + 可微遮罩學習哪個子圖最能預測正確性，輸出每步的機率 p；NIBS 則直接比對共識集，輸出連續信心值 c。最終低信心步驟就是模型最可能出錯的地方。

## 怎麼看這件事

這篇的核心直覺很乾淨：**正確路徑有共識，錯誤路徑有偏差**。這個想法和人類審查論文的方式相通——不同的有效解法在關鍵節點上通常殊途同歸。

對使用 API 的開發者來說，「黑盒」這個約束非常重要：這套方法完全不需要模型內部資訊，可以直接套在 GPT-4、Claude 等商業服務上。在高風險應用（醫療診斷、法律分析）中，能精準定位推理中哪一步最脆弱，比只知道最終答案正不正確要有用得多。

不過要留意，這套方法只對**有明確客觀答案**的任務有效。碰到見仁見智的主觀問題，「多數共識」不一定等於「正確」——這個假設在社會科學或創意任務中會失效。
