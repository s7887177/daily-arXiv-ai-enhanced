# 不知道相機參數,也能從一張照片框出物體的「立體盒子」

> 原始論文：MoCA3D: Monocular 3D Bounding Box Prediction in the Image Plane
> 作者·單位：Changwoo Jeon、Rishi Upadhyay、Achuta Kadambi（美國 加州大學洛杉磯分校 UCLA、韓國 延世大學）
> arXiv：2603.19538v2 ・ 分類：cs.CV

一句話說重點：研究者做出一個 AI,只要一張普通照片加上物體的 2D 方框,就能在畫面上直接畫出貼合物體的「立體盒子」八個角點與各自的深度,而且推論時完全不需要知道相機的內部參數——這正是過去網路照片做不到的地方。

---

## 背景:「立體框」很有用,但過去都要先知道相機參數

讓 AI 從單張照片理解物體的 3D 形狀(用一個立體長方盒「3D 邊界框」把物體框住),在擴增實境、機器人、視覺控制上都很有用。過去主流做法是:先把物體表示成「相機座標系裡的一個立體方塊或 6D 姿態」,在 3D 空間裡訓練和評估,等真的要畫到畫面上時,再把這個 3D 表示「投影」回像素。

問題出在這個「投影回畫面」的步驟:它需要知道相機的「內參數」(焦距、主點等鏡頭資訊)。可是現在很多新應用——例如擴散模型的圖像編輯、可控生成——直接需要「畫面上的投影 3D 角點(還帶深度)」來維持透視一致的版面控制。而對於網路上隨手抓的照片,相機內參數常常不知道、或不一致。這就形成一個矛盾:既有方法產出的 3D 角點,只有在「知道相機參數」時才用得上,在真實野外場景常常卡住。

一個直覺的替代方案是「直接從 2D 框回歸出角點座標」,但前人發現直接回歸角點很「稀疏」,梯度訊號少、效果會變差。所以作者改用另一種思路。

## 怎麼做:把「找角點」變成「逐像素的密集預測」

作者提出 **MoCA3D**(單眼、與類別無關的 3D 模型)。輸入是一張 RGB 照片加上一個貼緊物體的 2D 方框,輸出是這個物體投影 3D 立體框的八個角點,以及每個角點各自的深度。關鍵是:**推論時不需要相機內參數**。(如果評估時剛好有內參數,可以把角點和深度抬升回共享的 3D 表示,以便和傳統 3D 偵測方法公平比較。)

核心設計是把「定位角點」這件事,從「直接吐出幾個座標數字」改成「密集預測」——預測「角點熱圖」和「深度圖」(就像對每個像素都猜一個答案),這樣訓練訊號豐富得多、結果更穩定準確。流程上用一個 DINOv3 視覺骨幹抽特徵,接一個「3D 幾何 Transformer」(以那個 2D 框當條件去引導),再經「密集模組」輸出角點熱圖與深度。作者還提出一個叫「像素對齊幾何」(PAG)的新評估指標,直接衡量「畫面上的角點與深度一不一致」,而不是繞道用 3D 指標。

## 結果:畫面幾何準很多,3D 指標持平,參數還少很多

實驗顯示 MoCA3D 達到當前最佳:在衡量「畫面上幾何貼不貼合」的 PAG 指標上提升約 22.8%,同時在標準的 3D IoU 指標上保持相當水準,而且可訓練參數最多比基線少 57 倍。作者還把 MoCA3D 套到一些「過去在相機參數未知時不切實際」的下游任務上(例如擴散式編輯、可控生成所需的透視一致版面),展示它的實用價值超越標準基線模型。簡單說:它在「畫面對齊」這件最被新應用需要的事情上明顯更好,在傳統 3D 指標上不輸,還更輕量。

## 做不到的地方

作者明確列出兩個限制。第一,MoCA3D 目前**假設立體框的八個角點全都可見**,所以遇到「被截斷」的物體(部分跑出畫面、或被遮住)會表現不佳。第二,只靠角點的幾何資訊,對「對稱物體」會有方向上的歧義(分不清正反/朝向)。作者提出未來可用「截斷增強的前處理」或「加入方向線索與輔助關鍵點」來緩解。此外,方法仰賴輸入一個貼緊的 2D 方框(論文中用 oracle 2D box),這在真實全自動流程中還需要前段提供。

## 怎麼看這件事

**為什麼值得在意?** 隨著擴散模型的圖像編輯與可控生成興起,「在畫面上要有準確、透視一致的 3D 角點」變成真實需求,而網路照片常常沒有相機參數。MoCA3D 把問題重新框定成「不依賴相機內參數、直接做畫面對齊的密集預測」,正好對上這個缺口,而且更輕量。

**哪裡該保留懷疑?** 這是預印本,且方法假設八角點全可見、需要一個貼緊的 2D 框輸入,對截斷與對稱物體有已知弱點。「在像素對齊指標上大幅領先」是針對特定需求的優勢,不代表在所有 3D 場景都全面勝出。

**怎麼理解這個研究方向?** 這代表單眼 3D 理解正從「以相機座標系的 3D 方塊為中心」轉向「以畫面對齊的幾何為中心」,以服務下游的生成與編輯應用。它的價值在於放寬了「必須知道相機參數」這個現實中常常無法滿足的前提,讓 3D 幾何在野外照片上變得真正可用。
