# 你跟 AI 聊了三個月「綠茶哥」的故事，今天傳一張照片問「他今天怎麼穿？」AI 應該秒答得出來

> 原始論文：Contextualized Visual Personalization in Vision-Language Models
> 作者·單位：Yeongtak Oh、Sangwon Yu、Junsung Park、Han Cheol Moon、Jisoo Mok、Sungroh Yoon（首爾大學、Upstage AI、三星電子、DGIST）
> arXiv：2602.03454v3 ・ 分類：cs.CV / cs.CL（多模態大模型・個人化）

一句話說重點：AI 模型現在很會描述照片裡有誰，但**不會把照片裡的人連到你過去在這個對話視窗講過的故事**——你說「Jeffrey 是個喝綠茶的男生，叫他綠茶哥」，AI 過幾天還是把那張照片裡的他認成 Martin Freeman。這篇提出一套訓練方法 CoViP，讓 VLM 學會「**先看照片裡有誰、再去翻你跟它說過的故事、把兩邊接起來**」。

---

## 先說情境：什麼叫「上下文化的視覺個人化」？

現在的視覺語言模型（VLM，例如 GPT-4V、Qwen-VL）對「描述照片」很厲害——你丟一張照片，它告訴你「這是一位穿黑色西裝的男士」。但它有個明顯的個人化缺口：

**它不知道這個人對你來說是誰。**

如果你過去三個月在這個對話視窗裡跟 AI 聊過「我有個朋友 Jeffrey，10/11 在 New Ryan 認識的，他不喝咖啡只喝綠茶，我給他取綽號叫『綠茶哥』」⋯⋯然後今天你丟一張 Jeffrey 的照片問「今天要跟照片裡的人開會，建議我穿什麼」——

現有的 VLM 會回答：「這位是 Martin Freeman，演過《辦公室》和《福爾摩斯》...」（**它認成名人，因為長得像**）。

理想的回答應該是：「喔，這是你的綠茶哥 Jeffrey！從 10/11 在 New Ryan 認識以來⋯⋯你今天要跟他見面對吧？要不要再聊聊他喜歡的綠茶？」

**這個能力不存在**。作者把它命名為 **contextualized visual personalization（上下文化的視覺個人化）**——VLM 必須做兩件事：(1) **辨識照片裡的視覺概念**，(2) **從累積的對話歷史中找到對應的個人記憶**，再(3) 把兩者整合進回應。

## 他們怎麼做：把「個人化看圖說故事」當作訓練 proxy

過去的個人化研究多半針對「簡單屬性辨識」（這是 user 的車、這是 user 的狗）。CoViP 處理的是更深的「**經驗層級記憶**」——名字、暱稱、互動歷史、約定俗成的關係。

核心想法：把整個「contextualized visual personalization」用 **personalized image captioning（個人化看圖說故事）** 當訓練 proxy task。理由是：要好好寫個人化的圖片描述，模型本來就需要做完整三步（看圖→翻記憶→整合敘述），這條訓練訊號可以同時打通其他下游任務。

技術組件：

1. **構建 benchmark**：論文做了一個新的 personalized image captioning 資料集，刻意設計成「不能用 textual shortcut（純從上下文猜答案）」——確保模型真的有用到視覺輸入。
2. **強化學習做後訓練（RL post-training）**：用上面的 captioning benchmark 當 reward signal 來 fine-tune VLM。
3. **Caption-Augmented Generation（CAG，推論時的字幕增強）**：推論時讓 VLM 先**自己生成個人化字幕**，再把這份字幕當作條件訊號去回答下游問題。等於模型自己對自己做提示工程。
4. **診斷型評估**：除了主任務，論文還設計一套**「反向診斷」測試**——刻意把上下文與視覺特徵錯位，看模型是不是真的有看圖、還是只是看到關鍵字就亂猜。

## 結果

- **CoViP（基於 8B Qwen3-VL）顯著超越同 size 與更大模型的開源、閉源 baseline**，在個人化字幕與多項下游任務都漲分。
- **閉源 VLM（GPT-4V 等）在診斷任務上不穩**：作者用反向診斷揭露出現有大模型也常常靠文字 shortcut 蒙混，遇到刻意設計的測試會崩。
- **CAG（推論時的字幕增強）是免訓練的擴充**，可以直接套到沒做過 post-training 的模型，仍有助益。

## 做不到的地方

論文相對誠實，但仍有限制：

- 主要場景假設「**整段對話歷史都放在 context 裡**」——這對短期對話可行，但**真正的長期個人助理**會卡在 context window 上限。
- 個人化標註資料是合成的，**真實 user 累積的對話樣貌與情緒**比這 dataset 還複雜。
- 沒有處理「**隱私層面**」：模型記得越多個人細節，泄漏風險也越大。
- 只測 VLM 內建的「閉迴路」記憶，跟外接 retrieval-augmented memory（RAG）的整合留給後續。

## 怎麼看這件事

**為什麼在意？** 真正能黏住使用者的 AI 助理，**不是聰明，是「記得」**。你跟它聊三個月、累積一堆細節，它若每次都對你像陌生人講話，就永遠是工具不是夥伴。CoViP 處理的是「**視覺**＋**個人記憶**」的接合點，這塊接通了，AR 眼鏡、智慧家庭、車載 AI 才真的能展開。

**哪裡該保留？** 「VLM 在診斷任務上不穩」是個重要結論，但要記得：**這些診斷任務本身是 CoViP 作者設計的**，不一定與真實使用場景對應。論文的 captioning benchmark 也是合成 + 半人工製作，真實長期記憶累積會是更亂、更碎、更含糊的樣子。

**怎麼理解這個方向？** 過去 VLM 研究主軸是「**更強的視覺辨識 + 更會聊**」；CoViP 把焦點轉向「**個人化記憶接通**」，這是 AI 助理通用化必經之路。RL post-training 在這領域變成主流武器（reward 從評估 benchmark 來），CAG 這種「**讓模型自己幫自己 prompt**」的技巧，跟 chain-of-thought 屬於同個家族——能比較廉價地榨出大模型內部已有的能力。
