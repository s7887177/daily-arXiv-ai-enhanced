# 大型視覺模型其實「眼睛裡飄著渣」：找出那些雜訊像素，AI 就能看清細節

> 原始論文：UniRefiner: Teaching Pre-trained ViTs to Self-Dispose Dross via Contrastive Register
> 作者·單位：Congpei Qiu、Zhaoyu Hu、Wei Ke、Yanhao Wu（西安交通大學）；Zhuotao Tian（哈爾濱工業大學深圳）；Tong Zhang（中國科學院大學）
> arXiv：2605.19622v1 ・ 分類：cs.CV 電腦視覺・表徵學習

一句話說重點：大型視覺 Transformer 模型（ViT）在分類整張圖時表現很好，但要精細到「逐像素切割」時卻常出錯——因為它的特徵圖裡有高達 40% 的「雜訊 token」在亂跳。這篇把雜訊分成三種類型、設計一個「專門吸雜訊的暫存欄」（contrastive register），只要在 5000 張圖上微調幾個 epoch，就能讓 80 億參數的 EVA-CLIP-8B 在 ADE20K 分割任務上多衝 9.4 個百分點，反過來超越專門的視覺模型 DINOv2。

---

## 先說情境：大模型「會看圖」不等於「會精準指出位置」

把圖丟給 EVA-CLIP-8B 這類大型視覺-語言模型，問它「這是什麼？」它能答得很好。可是如果要它做「語意分割」——也就是把圖中每個像素標出「這裡是天空、這裡是腳踏車、這裡是路面」——表現往往輸給體型小得多、專門做視覺的 DINOv2。

研究者把模型內部的特徵圖（feature map，模型把圖切成一格一格小方塊後每格的「想法」）視覺化，看到一個直觀現象：許多格子裡的「想法」根本對不上它原本在圖上的位置——他們稱這種錯位的格子為 **spurious token（雜訊 token，原意「假的、不該出現的」token）**。

## 他們怎麼做

第一步是把雜訊分類。作者實際拆解 CLIP、DINOv2、EVA-CLIP、SigLIPv2、InternViT 這些主流大模型後，發現雜訊不是單一現象，而是**三種不同毛病**：

1. **Fixed Pattern（固定模式）token**：不論輸入什麼圖，這格永遠長一樣，等於沒在記錄內容。
2. **Global Proxy（全域代理）token**：這格不記錄自己位置的東西，反而像偷渡了「整張圖的摘要」進來。
3. **Attention Hijackee（注意力被劫持）token**：自己本來有內容，但被鄰居比較搶眼的 token 透過 self-attention 機制「蓋台」，原本意思被覆寫掉。

過去研究只把雜訊當成單一現象——「離群值就是雜訊」。作者證明這太天真：在 EVA-CLIP-8B 這種大模型裡，三類雜訊加起來可以**超過 40%**，光抓離群值遠遠不夠。

第二步是「教模型自己丟掉這些渣」。作者用 **register token**（暫存格 token，是一種把雜訊集中往某個固定位置塞、最後再丟棄的技巧）的概念，但加上一個關鍵設計：**對比式暫存格（Contrastive Register）**。原本的 register token 是被動等雜訊跑進來，碰到大模型雜訊太多就吃不下；對比式版本明確地用兩個目標訓練：
- 影像 token 對齊「過濾後的乾淨 token」，把正常語意保下來；
- 暫存格 token 對齊「偵測出的雜訊 token」，把垃圾全部吸過去。

加上一個「分散度損失」逼影像 token 和暫存格 token 別長得太像,確保垃圾不會回流污染主表徵。整套用輕量化的 LoRA 微調實作,**不改模型結構**,只在 5000 張小資料集上跑幾個 epoch 就完成。

## 結果

- **EVA-CLIP-8B 在 ADE20K 語意分割任務**:51.9% mIoU(+9.4%),超過 DINOv2 的 49.1%——這代表這個原本「會看圖卻不會指位置」的大模型,被矯正後反而打贏了專門做視覺的小模型。
- **零樣本分割準確率**:最高提升 22%。
- **可在 EVA-CLIP-8B、InternViT-6B 等 60-80 億參數量的巨型模型上跑**,改善是一致的,不是個案。

## 它做不到 / 沒解決的

作者誠實寫出限制:這方法是**事後補救**(post-hoc refinement),不是治本——它沒解釋這些雜訊一開始為什麼會出現,也無法讓模型在預訓練階段就避免長出雜訊。另外,它需要的 5000 張微調圖、雖然不多但仍是「有標準」的乾淨資料,在某些封閉場景(例如醫療影像)可能不容易湊出對應資料來微調。論文也沒給出在影片或 3D 任務上的測試結果。

## 怎麼看這件事

**為什麼在意?** 大型視覺-語言模型(Vision-Language Model)現在是各種 AI 應用的基石,但「拿大模型直接做密集預測」一直是業界痛點——你需要分割地物、估計深度的時候,反而要回頭用小一號的專門模型。這篇等於提供了一條「不重訓、直接矯正」的路徑,把已有的巨型模型的潛在空間能力解鎖出來。

**哪裡該保留懷疑?** 提升 9.4 個百分點聽起來很多,但這仍是 benchmark 上的數字,實際下游應用(例如自動駕駛的分割)還需要在更接近真實場景的資料上驗證。另外論文沒比較不同 LoRA 秩、不同訓練圖數量的敏感度細節,讀者最好等實作公開後再做判斷。

**怎麼理解這個方向?** 這代表大模型研究進入「拆解內部、針對性修補」的階段——不再只是「再做大、再多訓一點」,而是承認大模型有特定的內部毛病,並用診斷-治療的思路去解決。對下游使用者來說,這意味著未來可能不需要每次都另起爐灶訓專用模型,而是在通用大模型上做小手術即可。
