# 「他在哭但說『我很好』」——AI 解讀情緒總在這種衝突訊號上崩盤,這篇用「情緒分類樹」當外掛字典

> 原始論文:Navigating the Emotion Tree: Hierarchical Hyperbolic RAG for Multimodal Emotion Recognition
> 作者·單位:Zeheng Wang、Bo Zhao、Yijie Zhu、Zhishu Liu、Hui Ma、Zitong Yu(大灣區大學);Ruixin Zhang、Shouhong Ding(騰訊優圖實驗室);Qianyu Xie(香港中文大學深圳)
> arXiv:2605.18884v1 ・ 分類:cs.LG / cs.CV

一句話說重點:大灣區大學 + 騰訊優圖團隊提出 HyperEmo-RAG——把心理學那套「情緒像樹一樣有層級」的分類學,**塞進雙曲空間(hyperbolic space, 一種數學上特別適合表達樹狀結構的彎曲幾何)**當外部知識庫,讓多模態大模型在判讀人類情緒時不再把「快樂、興奮、欣喜」當作互不相關的標籤,而是按樹從粗到細逐步收斂——對話、語音、表情三種訊號衝突時也比較不會亂猜。

---

## 先說情境:讓 AI 看影片+聽聲音+讀字幕來判斷你現在的情緒,難在哪?

**多模態情緒辨識(Multimodal Emotion Recognition, MER)**是讓機器同時看臉、聽語氣、讀文字,判斷一個人此刻是開心、生氣、悲傷還是困惑——應用場景包括線上教學偵測學生疲倦、心理諮商輔助、客服情緒應對等。

兩個老問題:

1. **情緒是有層級的,但 AI 把它當扁平標籤。** 心理學的情緒分類其實是一棵樹:Joy(喜悅)底下分 Cheerfulness(歡樂)、Cheerfulness 又分 Ecstasy(狂喜)、Delight(高興)、Amusement(逗趣)。大模型 LLM 學情緒時,把這些當成獨立分類詞,**就會搞混細微差異**。
2. **訊號衝突 → 幻覺。** 看到臉哭、聽到聲音哽咽、文字寫「我沒事」——多模態訊號彼此打架時,LLM 傾向**過度詮釋雜訊**,瞎掰一個答案,術語上叫「幻覺」。

## 他們怎麼做:把情緒樹塞進雙曲空間,用 RAG 當外部知識

**第一招:層級雙曲嵌入(Hierarchical Hyperbolic Grounding)。**

普通向量空間(歐氏空間)很難表達樹狀結構——樹有「指數膨脹」的性質(每往下一層孩子數可能翻倍),歐氏空間裝不下太多層級而不擠在一起。**雙曲空間**(他們用的是 Poincaré ball 模型)就像一個彎曲的世界:離原點越近、半徑越大,適合裝樹根與樹葉。作者把:
- 情緒分類樹的每個節點
- 訓練用的多模態樣本(文字+語音+影像)

**一起嵌入到同一個雙曲空間裡**。然後設計**層級 beam-search 思辨流程**:推理時先在樹的粗層級(Joy 還是 Sadness)找候選,再往細層級(Cheerfulness 還是 Pride)收斂,而不是一次跳到最細。

**第二招:結構化證據注入(Structured Evidence Injection)。**

光把樣本找回來給 LLM 還不夠——傳統 RAG 把檢索到的樣本當成一堆無序的「例子」丟給 LLM,結構資訊全丟失。作者把檢索結果組成一張**思辨證據圖(Deliberation Evidence Graph, DEG)**,顯式連接情緒節點與證據樣本,然後用兩個機制把這張圖塞進 LLM:
- **Tree-Aware Attention:**讓 attention 機制感知到圖中節點的樹狀距離(同一支樹枝的相似度高)。
- **EmotionGraphFormer:**專門編碼這張圖,輸出結構化表示交給 LLM 當上下文。

訓練時還加兩個輔助損失:**樹距離感知對比損失**(讓情緒類別間的語意距離與樹距離一致)與**路徑一致性損失**(讓查詢樣本與選中情緒原型的路徑對齊)。

## 結果:在多個 MER benchmark 顯著贏過既有方法

論文在多個多模態情緒辨識資料集上測試,HyperEmo-RAG 顯著超越既有 LLM-based MER 系統(AffectGPT、EmoLLM、EmoLLaVA)與多模態 RAG 方法。消融顯示:**雙曲空間的層級嵌入**比歐氏空間的扁平嵌入收益大;**結構化圖注入**比把樣本當無序樣本丟給 LLM 收益大;兩者結合才有最佳效果。

![Figure 1:傳統 LLM 做情緒辨識的限制(上)vs. HyperEmo-RAG 的做法(下)。傳統 LLM 把表情、語氣、文字直接餵給大模型,當訊號衝突時(哭臉、tearful)會幻覺出「very happy」這種錯誤答案。HyperEmo-RAG 從粗(Primary Emotion: Joy)逐步往細(Secondary: Cheerfulness → Ecstasy/Delight/Amusement)搜尋情緒樹,再把結構化證據交給 LLM 作答。](assets/articles/2605.18884v1-fig1.webp)

這張圖是核心動機。**上半**:傳統 LLM 一次處理多模態輸入,沒有外部結構知識就容易幻覺——例子是輸入「哭臉、tearful」結果輸出「Very happy」這種離譜結果。**下半**:HyperEmo-RAG 把判斷拆成多步驟,先在情緒樹的粗層級確定「這應該屬於 Joy 系」,再下探到 Cheerfulness、再到 Ecstasy/Delight/Amusement,最後讓 LLM 在這個收斂的子空間中決定。這種「逐層深入」的方式比起一步到位的扁平分類更穩定。

## 它做不到 / 沒解決的

論文坦白:(1) **情緒樹是預先建好的固定知識庫**,如果某個應用場景需要的情緒類別不在樹裡(例如東亞文化特有的「氣到無語但不能發作」),需要重新擴充樹結構;(2) 雙曲空間的計算與訓練比歐氏空間複雜,有部署成本;(3) **多模態訊號衝突的判讀很大程度仰賴上下文與文化**,光靠分類樹未必能解決——例如「微笑掩飾悲傷」是文化現象,需要更深層的對話歷史。

## 怎麼看這件事

**為什麼在意?** 情緒辨識在心理健康、教學、客服都會落地。當 LLM 從「會說話」走到「能感知」,**最常翻車的就是訊號衝突的場景**——人本來就是矛盾的生物。把心理學的結構化知識當外掛塞進 LLM,是讓它從「瞎猜」往「有依據」走的一條路。

**哪裡該保留懷疑?** 情緒分類樹本身在心理學界都還有爭論(Ekman 六分法 vs. 維度論 vs. 文化特異性);這篇假設樹是給定的,但這個假設本身就有偏見。此外,「benchmark 上贏」不等於「真實應用中能可信地用於心理諮商」——情緒辨識用錯地方可能造成傷害。

**怎麼理解這個方向?** 「結構化外部知識 + 大模型」是 2025-2026 RAG 研究的主流路線。這篇展示了「即使是看起來很扁平的分類任務,只要該領域有層級結構,結構化檢索就能大幅幫助」。當 LLM 越來越強,**贏的關鍵不再是模型大小,而是怎麼把領域知識整理好塞給它**——這條路會在醫療、法律、生物學等知識密集領域繼續長大。
