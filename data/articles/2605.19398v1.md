# 圖生影片老是「靜止如畫」？找到動作被壓制的真正原因

> 原始論文：Rebalancing Reference Frame Dominance to Improve Motion in Image-to-Video Models
> 作者·單位：Wooseok Jeon 等（延世大學、GIST、Adobe Research）
> arXiv：2605.19398v1 ・ 分類：cs.CV / cs.AI

一句話說重點：圖生影片（Image-to-Video，I2V）模型產生的畫面常常靜止不動，根本原因是注意力機制對參考幀的「過度依賴」——只需在推理時調一個參數，不用重新訓練，就能讓影片動起來。

---

## 問題在哪裡

現代的文生影片（Text-to-Video，T2V）模型可以讓狗奔跑、火箭發射。但圖生影片（I2V）模型——給一張圖，讓它「動」起來——卻常常產生幾乎靜止的畫面。即使文字提示明確要求動作，模型也傾向讓畫面保持原樣。

這個問題之前都被歸咎於「影像條件訊號太強」，解法多半是直接削弱或修改輸入圖片的影響，但這樣就會損失原圖的保真度。

## 找到原因了

本文發現了一個更根本的機制：**參考幀主導效應（reference-frame dominance）**。

在 I2V 模型的擴散 Transformer（DiT）自注意力機制中，非參考幀的 query token 對參考幀的 key token 分配了**過多的注意力**，遠遠超過純文生影片模型的對應值。這讓參考幀的資訊被「過度傳播」到所有其他時間步，導致後續幀都緊貼參考幀、幾乎不動。

研究者用介入實驗驗證：人為**加強**這個注意力，影片更靜止；人為**減弱**它，影片動作增加——因果關係成立。

## 解法：Dynamic Motion Slider（DyMoS）

**DyMoS（動態動作滑桿）** 的做法極其簡單：

- 在推理的前幾個去噪步驟中，對「指向參考幀 key token 的注意力 logit」加上一個純量偏移值 γ。
- γ < 0：減弱參考幀主導，影片動作增加。
- γ > 0：強化參考幀主導，影片更靜態、更忠於原圖。
- γ = 0：原始行為。

整個過程：
- **不修改模型權重**
- **不修改輸入圖片**
- **不需要額外訓練**
- 僅在初始去噪步驟（而非全程）應用，保留後期細節生成的正常運作

## 結果

在四個主流 I2V 骨幹上（Wan 2.2、Wan 2.1、HunyuanVideo-1.5、CogVideoX-5B）：

- DyMoS 一致提升動態程度（VBench 動態分數提升 +33.3%），同時維持畫面品質和對參考圖的保真度。
- 額外推理時間極微（在 Wan 2.2 上只增加約 1.2%）。
- 提供連續的靜態↔動態調控——一個參數滑桿搞定，不需要針對每個骨幹重新實現。

## 做不到的地方

- γ 的最佳值在不同骨幹和不同場景下略有差異，使用者仍需試調。
- 只在初始去噪步驟應用的設計雖然有理論依據，但超參數（應用幾步、偏移幅度）沒有自動確定方法。
- 論文沒有涉及長影片或高解析度影片（4K+）的測試，能否維持效果未知。
- 方法本質是「減弱參考幀注意力」，在某些需要高度忠實於原圖的場景，可能因動作增加而引入視覺不一致。

## 怎麼看這件事

I2V 生成的「靜止問題」是一個廣泛存在的使用者痛點。DyMoS 的貢獻在於找到了問題的機制（注意力層的參考幀主導），而不是用 trick 強行提高動態度（如輸入圖片加噪音），因此解法更乾淨、不影響保真度。

不過，最終效果仍高度依賴 γ 的選擇，如何自動地為不同場景選擇最佳 γ（例如根據文字提示的動態強度自適應調整），是這個方向下一步的關鍵問題。
