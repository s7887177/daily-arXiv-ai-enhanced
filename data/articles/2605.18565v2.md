# AI 記憶力大考驗：資訊不斷被改寫時，誰還記得原本說了什麼？

> 原始論文：MINTEval: Evaluating Memory under Multi-Target Interference in Long-Horizon Agent Systems
> 作者·單位：Hyunji Lee、Justin Chih-Yao Chen 等（北卡羅來納大學教堂山分校、德州大學奧斯汀分校）
> arXiv：2605.18565v2 ・ 分類：cs.CL、cs.AI

一句話說重點：七個最先進的記憶增強 AI 系統在「資訊持續干擾更新」情境下的平均答題正確率只有 27.9%——最好的系統也才 33.4%，遠低於任何實用門檻。

---

## 背景：AI 的「記性」為什麼特別容易出錯？

人類和 AI 都有記憶干擾的問題：舊記憶干擾新資訊的接收（前攝干擾），新資訊又抹除舊記憶（後攝干擾）。這在軟體版本更新、醫療紀錄修訂、維基百科改版等現實場景中天天發生。

現有 AI 記憶系統的評測卻幾乎只測「靜態、獨立的事實回憶」——就像考「你上次去了哪個城市？」而不是「你去了十個城市，第三次去的是哪裡？期間又更換了兩次計畫」。這導致系統在現實部署中表現遠比測試數字差。

## 怎麼做：建一個貼近現實的「記憶壓力測試」

本文推出 **MINTEval**（長視野干擾記憶評測，Long-Horizon Memory under INTerference Evaluation），從四個真實場景取材：

- **狀態追蹤**（bAbI 資料集）：符號式事實反覆被覆寫
- **多輪對話**（HorizonBench）：使用者偏好在長期對話中隱式改變
- **維基百科修訂**：文章被連續更改，事實互相矛盾
- **GitHub 提交歷史**：程式碼跨版本演進，函式名稱與 API 不斷變動

每個情境設計了兩類問題：
1. **單一目標回憶**：包含「簡單（最新狀態）」和「歷史回溯（舊版本狀態）」兩種難度
2. **多目標聚合**：需要橫跨多次更新做排序、計數、多步推理

資料集共收錄 15,600 道問答題，每個情境平均 138,800 個 token，最長達 180 萬 token，是現有干擾型記憶評測中規模最大、干擾最密集的。

評測了七個系統：全文上下文 LLM、檢索增強生成（RAG）、HippoRAG、MemAgent、AtomMem、Mem-α、SimpleMem。

## 結果

**所有系統表現都慘**：
- 平均正確率 27.9%；最強的 MemAgent 也只有 33.4%
- 簡單回憶題平均 47.5%，勉強能用；歷史回溯題只有 21%，多目標聚合只有 26.5%

**錯在哪裡**（分解分析）：
- 記憶建構失敗（擷取或整合錯）→ 貢獻 41.7% 的錯誤
- 答題代理即使拿到正確資訊仍答錯 → 貢獻 25.2% 的錯誤

**三個系統類型各有致命弱點**（如圖右欄所示）：
- 全文上下文方法：計算成本高且超過 context window 限制
- RAG（檢索增強生成）：在有衝突的事實中常取回錯誤的版本
- 記憶增強代理：偏向覆寫、忽略舊資訊，回溯型問題失敗率最高

## 做不到的地方

- 資料來源以英文為主，多語言干擾場景未涵蓋
- 問題由 Gemini-3.1-Pro 自動生成（95.6% 人工驗證通過），自動生成可能帶有系統性偏差
- 這是評測工具，本身不提供改進記憶的方法——它揭示問題，但不給解方
- 測試的七個系統都是公開/特定框架，閉源商業系統（如 ChatGPT memory 功能）未被納入

## 想自己判斷這篇可不可信？

| 訊號 | 這篇的情況 | 怎麼解讀 |
|---|---|---|
| 資料規模 | 15,600 道題，覆蓋 4 個領域 | 不容易因資料量小造成過擬合評估 |
| 人工驗證 | 20% 樣本六位標注者驗證，通過率 95.6% | 自動生成資料的品質有一定保障 |
| 評測系統多元 | 涵蓋全文 LLM、RAG、多個記憶代理框架 | 結論不只適用於某一類系統 |
| 錯誤分解分析 | 分開計算「記憶建構失敗」與「答題失敗」比例 | 診斷細緻，讓改進方向比較清晰 |
| 資料與程式碼公開 | GitHub 連結已附 | 可重現 |

## 怎麼看這件事

27.9% 的平均準確率讓人警醒——這意味著，如果你讓現有最好的 AI 記憶系統去追蹤「一份文件被反覆修改後的內容」，它有七成機會給出錯誤答案。

更核心的問題是：現有系統被設計成「關注最新狀態」，而不是「追蹤完整演化歷史」。這在資訊穩定不變的情境下沒問題，但在任何資訊會被更新、矛盾、撤回的現實場景——也就是幾乎所有真實場景——這種設計就是個根本性的盲點。

MINTEval 的意義在於提供了一個可測量的壓力測試，讓研究者知道現在的系統到底離「可用的長期記憶」有多遠。答案是：還很遠。
