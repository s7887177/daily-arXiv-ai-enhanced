# 把 MRI 重建變成「下一個字猜什麼」：用 ChatGPT 風格的離散預測重建掃描影像

> 原始論文：Next-Acceleration-Scale Prediction for Autoregressive MRI Reconstruction
> 作者·單位：Yilmaz Korkmaz、Vishal M. Patel（Johns Hopkins University 約翰霍普金斯大學）
> arXiv：2605.19354v1 ・ 分類：醫療影像重建・自回歸模型

一句話說重點：MRI 掃描很慢，加速採樣後重建會「糊掉細節」。這篇把重建問題搬到**離散 codebook 空間**做「**下一個加速倍率的預測**」——像 GPT 從「the cat」猜「sits」，模型從「8 倍加速的潛在 token」猜「4 倍加速的 token」一路猜到完整影像；還搬了 LLM 後訓練的「on-policy 特權蒸餾」技巧，讓老師看完整資料、學生只看欠採樣資料，重建細節明顯銳化。

---

## 背景：MRI 解析度跟掃描時間之間的兩難

MRI 是醫院最重要的軟組織造影工具，但**很慢**——一次完整掃描動輒 20-40 分鐘，病人不能動、不能呼吸太大聲。為了縮短時間，臨床會用「加速採樣（accelerated MRI）」：只採完整 k-space（頻率空間）的一部分，剩下用演算法或深度學習補。

過去 5 年深度學習已經能在 4 倍、8 倍加速下做出可看的影像，但**到 16 倍、32 倍 極限加速**時，主流方法（CNN、Transformer、Diffusion）會出現一個共通問題：**全局結構回來了，但高頻細節（小血管、皮層紋理）被「平均掉」**——因為這些方法在「像素連續空間」做預測，自然會傾向給出多個可行解的平均值，畫面變糊。對放射科醫師來說，這種「看似乾淨但細節消失」的影像比看得到雜訊還危險。

## 怎麼做：把「重建」翻譯成「猜下一個 token」

論文有兩個關鍵設計：

**(1) 把重建搬到離散 codebook 上做 next-acceleration-scale prediction**

近年「Visual Autoregressive（VAR）」這類模型把圖片表示成「**離散 codebook tokens**」——影像被切成 token grid，每個 token 從一本「視覺字典」裡選一個 entry。這跟 GPT 把句子表示成 word tokens 異曲同工。VAR 原本是「**next-resolution-scale prediction**」（從小解析度猜大解析度）。

作者改造這個設定：把多層級不再對應「不同解析度」，而是對應**不同加速倍率**（R=32 → R=16 → R=8 → R=1 完整採樣）。模型從「最稀疏的 R=32 token」開始，逐層往「完整 R=1 token」推進。離散 codebook 等於是一本「**合理解剖結構的字典**」——模型只能從這本字典挑 token，**不可能生出「臉部模糊不成形」的非解剖結構**，這是離散表示帶來的天然 inductive bias。

具體架構：作者開發 **AQ-VAE**（Additive multi-input VQ-VAE）來把不同加速等級的 MRI 餵進共享 codebook，再用 **cross-attentive autoregressive transformer** 做 token 預測。

**(2) on-policy 特權蒸餾（privileged information distillation）**

訓練時有個 well-known 落差：學生在訓練時看的 context 跟推論時看的不一樣（teacher forcing vs autoregressive rollout），這就是「**exposure bias**」。LLM 圈最近流行的解法叫「**on-policy distillation**」：學生用自己的 rollout 生資料、老師給回饋。

作者把這套搬到 VAR：
- 學生在自己的 rollout（基於欠採樣 MRI）上生 token 序列；
- 老師看完整的 fully-sampled MRI（這是「**特權資訊**」——推論時學生看不到），對學生的每一步提供 ground truth 級的回饋；
- 推論時學生獨自運作。

這個 trick 大幅減少了「學生在錯誤 context 下繼續錯下去」的累積誤差，把模型訓練範式跟推論行為對齊。

## 結果

在 fastMRI 公開基準上（含 PD、PDFS 多種對比、knee、brain 兩個部位）：

- **極限欠採樣（R≥16）下，PSNR/SSIM 都優於現有 SOTA**（包含 CNN、Transformer、Diffusion baseline）。
- **高頻解剖結構保存度**（用 high-frequency PSNR 衡量）明顯改善，符合「離散表示防糊化」的設計初衷。
- 跨採樣樣式（Cartesian、隨機、Radial）、跨解剖部位都有一致提升。
- Ablation 顯示「特權蒸餾」單獨貢獻 0.3-0.5 dB PSNR。

## 圖解：「下一個解析度」vs「下一個加速倍率」

![Figure 1：VAR 原版「下一個解析度」（左，狗的影像逐步變大） vs 作者「下一個加速倍率」（右，腦 MRI 從 R=32 逐步變清晰到 R=1）。](assets/articles/2605.19354v1-fig1.webp)

這張左右對比圖一眼就看懂作者的核心改造。**左側 VAR**：傳統視覺自回歸模型把一張狗的圖片切成 5 個解析度等級（S1 是最小、S5 比較大、S10 是完整），模型從 S1 出發，一層一層生成下一個解析度的 token，最後得到完整影像——這叫「**單輸入殘差潛在金字塔**」。

**右側 Ours**：作者把「金字塔」的語義從「解析度差別」改成「加速倍率差別」。同一張腦 MRI 在 R=32 倍欠採樣下幾乎看不出形狀，R=16 出現腦室輪廓，R=8 細節更多，R=1 是完整資料——這叫「**多輸入加性潛在金字塔**」。模型從欠採最嚴重的 R=32 token 開始，預測 R=16 token、R=8 token、… 最後到 R=1 完整重建。

這個改造的妙處在於：**每一層的 token 都有對應的真實欠採樣資料當錨點**，不是完全憑空生成。離散 codebook 又確保中間 token 只能從「**合理的解剖結構字典**」中挑，避免擴散模型那種「平均出一坨糊」的現象。

## 它做不到 / 沒解決的

- **訓練成本高**：VAR + 特權蒸餾需要同時跑老師、學生兩個網路，計算量比純前向重建高。
- **離散 codebook 的容量上限**：codebook 太小會把「沒見過的罕見病灶」當成最相似的常見結構去重建——這在臨床上是嚴重風險。論文沒深入處理 OOD（out-of-distribution）案例。
- **適用對比有限**：fastMRI 主要是 knee、brain，臨床真實 protocol（心臟、胎兒、腹部）多樣性更大，泛化能力需要驗證。
- **沒做臨床讀片研究**：所有指標都是技術性 PSNR/SSIM，沒有放射科醫師參與盲讀比較。

## 怎麼看這件事

**為什麼在意？** MRI 重建的瓶頸已經從「能不能看到大致形狀」走到「**能不能保住細節以利診斷**」。對病患而言「掃描縮短一半」是直接福音，但代價是醫師可能因影像細節喪失誤診——這是個直接的醫療品質風險。任何能在 16x 加速下保住高頻細節的方法都有立刻被臨床採用的潛力。

**哪裡該保留懷疑？** 用「離散 codebook」當解剖字典是雙刃劍：對常見結構效果好，對罕見病灶可能變成「**用最像的常見結構填補**」，這在重建出來的影像上肉眼難察覺，但對診斷可能災難性。需要更多 OOD 評估。

**怎麼理解這個方向？** 這篇是「**把 LLM 的範式遷移到視覺**」這條大趨勢在醫療影像的具體實作：離散 tokens、autoregressive prediction、on-policy distillation——這些都是 GPT 體系的標配。當視覺模型開始用語言模型的訓練範式，後訓練、RLHF 這類技巧也可能跟著進入醫療影像領域，是一個值得關注的範式融合。
