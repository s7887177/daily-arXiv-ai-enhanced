# AI 把圖片切成小方塊來理解，但「一律切一樣多塊」很笨——這篇教它看圖片內容決定切幾塊

> 原始論文：Mutual Enhancement Between Global Tokens and Patch Tokens: From Theory to Practice
> 作者·單位：Xiusheng Huang、Xin Jiang、Jun Zhao、Yequan Wang、Kang Liu（中國科學院自動化研究所、中國科學院大學人工智慧學院、北京智源人工智慧研究院）
> arXiv：2605.16384v1 ・ 分類：cs.CV

一句話說重點：AI 在「讀圖」前會先把圖片切成一堆小方塊（叫 token），但現有做法不管圖簡單還是複雜都切一樣多塊——簡單圖浪費、複雜圖資訊不夠；這篇先用資訊理論證明這個毛病的兩個源頭，再做一個能「看內容多寡決定切幾塊」的方法，畫質更好、速度快 8.7 倍。

---

## 背景／問題

AI 在處理圖片前，得先把圖「翻譯」成它能算的東西——這道工序叫「視覺 token 化」（discrete image tokenization）。簡單說：把整張圖切成許多小方塊（patch），每塊壓縮成一串代碼，AI 再從這些代碼去理解或重建圖片。一個好的 token 化器，本質上就是個壓縮器：用最少的代碼，保住最關鍵的資訊。

問題出在現有做法**對所有圖片用同一個固定壓縮率**，不管這張圖是一片藍天（資訊很少）還是繁複的市集（資訊很多）。結果：

- 簡單的圖被切太多塊 → 一堆冗餘、浪費算力。
- 複雜的圖塊數不夠 → 關鍵資訊被丟掉、重建出來糊掉。

作者用「資訊熵」理論（衡量資訊量多寡的數學工具）嚴格證明，現有「只靠小方塊」的做法有兩個根本缺陷：

1. **資訊不足。** 光靠那些小方塊，數學上就無法完整捕捉整張圖的「全局資訊」（例如整體結構、語意），重建誤差有一個降不下去的下限。
2. **資訊冗餘。** 那些小方塊彼此之間有大量重複資訊。

更關鍵的是：過去的方法把「補全局資訊」和「砍冗餘」當成兩件分開的事在處理，沒有一個有理論依據、又整合在一起的解法。

## 怎麼做

作者提出 **TaTok**（一個「有理論根據的自適應 token 化框架」），用兩個互補機制同時對付上面兩個缺陷：

- **加入「全局 token」補資訊不足。** 他們從理論推導出：必須額外引進一種「可學習的全局 token」，專門記錄整張圖的整體語意與結構。它跟以往那種附帶的全局特徵不同——它被訓練成「最小化條件熵」，等於直接強化「這串代碼」和「原圖」之間的共享資訊。論文還用定理證明，加了它能把重建誤差的理論下限往下壓。
- **動態 token 過濾（DTF）砍冗餘。** 這個演算法依「率失真理論」（在「壓多小」與「能容忍多少失真」之間取最佳平衡的理論），動態算出「全局 token + 幾塊小方塊」剛好夠重建這張圖。做法是：把每個小方塊按「在已知全局資訊下，它還能額外貢獻多少獨特資訊」排序，從最有料的開始累積，直到資訊夠了就停——資訊豐富的留下，重複的濾掉。於是塊數會隨圖片的資訊密度自動調整。

值得注意：TaTok 是第一個把「全局 token」和「動態過濾」統一進一個端到端可訓練框架、又不增加推論負擔的 token 化器。

## 結果

- 在 ImageNet 256×256（一個標準圖像基準）上，TaTok 平均只用約 56 塊 token，重建品質指標 rFID 達 1.51，**贏過用 256 塊的 MaskGIT-VQGAN（rFID 2.28）和用 57 塊的 TiTok-B-57（rFID 1.75）**——更少的代碼、更好的保真。
- 接上同一個生成器後，生成品質 gFID 達 1.89，遠勝同生成器下的 MaskGIT-VQGAN（6.18）與 TiTok-B-64（2.48）。
- 速度上，相較高品質的擴散模型有約 **8.7 倍**的取樣加速，畫質指標相對前法有約 1.3 倍改善。
- 兩個受控實驗也印證了理論：(1) 加 16 個全局 token 就能讓重建誤差降約 30%，再多無益——證明缺的是「全局資訊」而非「更多塊」；(2) 砍掉一半小方塊對品質幾乎無影響，超過一半才崩潰——證明小方塊裡確實有大量冗餘。

## 做不到的地方

這篇是「token 化器」這一層的改進，重點在「把圖壓得更聰明」，不是端到端的圖像生成系統；最終生成品質仍取決於搭配的生成器。實驗集中在 ImageNet 256×256 這個解析度與資料集，更高解析度、其他資料分布下的表現論文未充分展開。理論證明依賴對自然圖像分布的若干假設（如局部平穩性），是分析框架的前提而非無條件成立。另外，文中部分超參數（如全局 token 數設 16、碼本大小 4096）是依經驗在「品質 vs. 效率」間取的平衡，換場景可能需重新調。

## 怎麼看這件事

**為什麼值得在意？** 「token 化器」是現代視覺與多模態大模型的地基——所有下游的理解、生成都建在它把圖壓成的代碼上。地基若浪費（簡單圖塞太多塊）或漏資訊（複雜圖塊不夠），上層再強也事倍功半。這篇罕見地先用資訊理論把問題的根因「證明」出來，再對症下藥，方向扎實。

**哪裡該保留懷疑？** 這是預印本，關鍵理論證明放在附錄、依賴對圖像分布的假設；實驗也集中在單一解析度與資料集。8.7 倍加速、畫質改善是漂亮成績，但這是在受控基準上的數字，換到更大、更雜的真實場景能否同樣穩，仍待更廣驗證。

**怎麼理解這個研究方向？** 這是「自適應壓縮」思路在視覺領域的體現：與其對所有圖一視同仁，不如讓系統依內容資訊密度動態分配資源。這種「按需分配」的設計，在追求又快又省又準的多模態大模型時代，是很實用的工程方向。
