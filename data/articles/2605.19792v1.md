# 拆 AI 看圖認物的「腦回路」：只有極少數注意力頭在管定位這件事

> 原始論文：Mechanisms of Object Localization in Vision–Language Models
> 作者·單位：Timothy Schaumlöffel、Martina G. Vilas、Gemma Roig（德國法蘭克福歌德大學 + Hessian Center for AI）
> arXiv：2605.19792v1 ・ 分類：電腦視覺・機械可解釋性

一句話說重點：你問 ChatGPT-Vision「貓在圖片裡哪個座標」、它真的能用像素座標回答——但模型內部到底怎麼「知道」物體位置？這篇用機械可解釋性 (mechanistic interpretability) 工具拆開 LLaVA-1.5 和 InternVL-3.5 兩款主流視覺語言模型，發現定位是靠**「容器化」(containerization) 機制**：物體周圍的視覺 token 形成一個「邊界框」，**裡面的語意排列其實不太重要**。而且**只有極少數的注意力頭真正在做這件事**，而且分類與定位用的頭幾乎不重疊。

---

## 背景：VLM 能看圖認物，但我們不知道它怎麼做到的

這幾年的「視覺語言模型」（Vision-Language Model, VLM）長這樣：

1. 一個視覺編碼器（通常是 CLIP 的 ViT）把圖切成一堆 patch，每個 patch 變一個向量（token）。
2. 一個 MLP 把這些視覺 token 投影到語言模型的嵌入空間。
3. 一個大型語言模型（LLM）把圖 token 和文字 token 一起讀，吐出答案。

代表作有 LLaVA、InternVL、Qwen-VL、ChatGPT Vision 等。它們在「視覺問答」、「描述圖片」表現都很好——也包括「給我物體的 bounding box 座標」這種需要精確空間能力的任務。

但有個矛盾：**CLIP 是用「全圖-文字配對」訓練的，本身對「像素級精確位置」並不擅長**。那為什麼把它包進 VLM 後，模型卻能講出座標？這個機制過去沒被仔細拆過——分類機制已經被研究得不錯，但定位（localization）這件事的內部運作幾乎是黑盒。

## 怎麼做：用四把「拆模型工具」逐層問

作者用一整套機械可解釋性的探針工具，包括：

- **Token 消融**：把某些視覺 token 換成「ImageNet 平均向量」（移除特定資訊），看模型行為怎麼變。
- **注意力擊倒** (Attention Knockout)：把指定的注意力連線切掉，看哪些連線是關鍵。
- **因果中介分析** (Causal Mediation Analysis, CMA)：標準的因果工具，量化「某個注意力頭」對最終預測的因果貢獻。
- **位置解碼** (Positional Decoding)：去問「模型內部還記得每個 token 在 2D 上的位置嗎」。

研究用 COCO 資料集（過濾後 1720 張圖、2248 個物體標註），並額外做一份「**移除物體**」對照組——把目標物用 LaMa（一個圖像修補模型）抹掉，留下背景。只保留「原圖能對、移除後就不能對」的樣本，**剔除模型靠脈絡瞎猜的成份**，確保分析的是「模型真的看到了物體」的情況。

## 主要發現一：定位是靠「容器化」(containerization)

模型怎麼知道物體在哪？答案出乎意料——**不是看物體的內部細節，而是把物體周圍的 token 圈成一個「容器」**。

具體說：當作者把物體區域內部 token 的「語意安排」打亂（保留 token 數量、但內容混亂），**定位結果幾乎不變**；但把「邊界 token」改掉，定位就明顯掉。

這意味著模型是這樣思考的：
- 「**這些 token 屬於同一個物體**」這件事被編碼進視覺 token 的群組關係。
- 物體的「**外形與邊界**」是定位的主要訊號。
- 物體**內部「畫的是什麼」**對 bounding box 來說反而不那麼重要——這部份對分類比較重要。

## 主要發現二：只有極少數注意力頭在管這件事

最戲劇性的發現在 Figure 4：

![四張「注意力頭因果貢獻熱圖」(Mediation Fraction)：上排是 LLaVA-7B（左=定位、右=分類），下排是 InternVL-3.5-8B（左=定位、右=分類）。橫軸是「頭」(Head, 0–32)，縱軸是「層」(Layer, 0–32)。顏色越亮黃代表該注意力頭對任務貢獻越大。LLaVA 的關鍵頭集中在第 11–16 層；InternVL 的關鍵頭集中在第 18–28 層。同一個模型內，定位和分類用的高亮頭幾乎不重疊。](assets/articles/2605.19792v1-fig1.webp)

每張小圖是「模型內部所有注意力頭」的一張因果貢獻地圖。LLaVA-7B 一共 32 層 × 32 頭 = 1024 個頭，但**亮黃的只有零星幾個**——只有不到 20 個頭真正在做關鍵工作，其他都在做配角。InternVL-3.5-8B 也類似，只有 18 個頭左右。

更有意思的是：
- **同一個模型內，「定位」用的頭和「分類」用的頭幾乎是兩組不同的頭**——雖然早期處理層有部份重疊。
- LLaVA 的關鍵頭集中在 **早中層**（第 11–16 層），InternVL 集中在 **中晚層**（第 18–28 層）。架構不同導致關鍵運算位置不同。
- **定位因果上「依賴」分類關鍵頭**——也就是說，模型是先確認「這是貓」、再決定「貓在哪」，順序明確。

## 主要發現三：1D 序列裡的 2D 結構

這個更精妙：LLM 接收的 token 是「一維序列」（patch 被攤平），但模型仍能輸出 2D 座標。怎麼做到？

作者發現：
- **多模態投影層裡殘留的位置訊號**（從 CLIP 的位置編碼帶過來的痕跡）
- **角落 anchor token**（四個角的 patch 訊號特別強）

這兩件事加起來，**就足夠讓 LLM 重建一個近似的 2D 網格**。模型沒有被明確教導 2D 結構，但它從這些「殘留訊號」自己拼出來。

## 主要發現四：多視角架構分工明確

InternVL-3.5 用了「**多視角處理**」——一張高解析度全圖被切成 6 個 448px tile（local views），加一個低解析度全圖（global view）一起餵進去。作者發現：

- **global view 是定位的主要訊號來源**——因為它看得到整體佈局。
- **local views 主要為分類做精修**——尤其對小物體，能看清細節。
- 這兩個視角**互補，而非冗餘**。

## 做不到的地方

- **只研究了兩個模型家族**（LLaVA、InternVL）。Qwen-VL、Claude、GPT-4V 是否有同樣的容器化機制？未知。
- **CMA、attention knockout 等工具本身有方法論爭議**——「某個頭重要」可能因為其他頭代償。論文有用多種工具交叉驗證，但仍是「相關性 + 因果干預」，不是物理意義上的因果。
- **沒有提供「下一步怎麼做」**——這篇是純診斷論文，告訴你「定位用了什麼回路」，但沒提「該怎麼設計更好的 grounding 損失函數」。後續研究空間大。
- COCO 是常見資料集，模型可能間接見過——雖然作者用 inpainted 對照組減輕這個顧慮。

## 怎麼看這件事

**為什麼在意？** 機械可解釋性是 AI 治理、AI 安全、模型設計三條線的交會點。當我們不知道「模型怎麼看到貓的位置」，要做 grounding 任務（讓 AI 指出文件裡的關鍵段落、AR 場景裡的物體）就只能靠試錯。如果定位真的是少數頭在做，**未來可以用很小的代價直接強化這幾個頭**——比 retrain 整個模型省太多。

**哪裡該保留懷疑？** 「容器化」、「少數頭」是強的概括，但 VLM 之間的差異很大（LLaVA 簡單、InternVL 複雜，未來的 GPT-5 視覺、Claude 視覺更不一樣）。把這個結論硬套到「所有 VLM」是過度推廣。論文也只在 COCO 這類「日常物體」上測，醫學影像、衛星圖、文件這些情境的機制可能不同。

**怎麼理解這個方向？** 「**機械可解釋性走進多模態**」是 2024–2026 一個明顯的研究方向——Anthropic 的 SAE（稀疏自編碼器）逐步在視覺模型上開花，這種「逐頭、逐層拆解」會越來越成熟。對於想 fine-tune 自己 VLM 的人，這類論文價值很高：它告訴你「**該動哪幾層、哪幾頭，其他層動了沒用**」。
