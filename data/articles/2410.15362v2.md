# 八倍效率「越獄」AI：研究者揭露 LLM 安全防線的新漏洞
> 原始論文：Faster-GCG: Efficient Discrete Optimization Jailbreak Attacks against Aligned Large Language Models
> 作者·單位：Xiao Li、Wei Zhang、Xiaolin Hu 等（清華大學、Sea-Fill、杜克大學、奧爾堡大學、中國腦研究院）
> arXiv：2410.15362v2 ・ 分類：cs.LG、cs.AI、cs.CL、cs.CR

一句話說重點：研究人員找出現有最強自動越獄攻擊 GCG 的三個效率瓶頸，改良後只需八分之一的計算次數，就能讓五款主流 AI 助手平均 78% 的機率「說出不該說的話」。

**注意：本文涉及 AI 安全漏洞研究，原論文含可能有害文字。**

---

## 背景：AI 安全防線可以被自動化突破

現代大語言模型（LLM）在訓練時都會進行「對齊（alignment）」——讓模型拒絕回應有害請求，如「教我製作武器」。但這道防線並不牢固。

「越獄（jailbreak）」攻擊試圖繞過這個防護層。早期越獄靠人類手動設計奇特的提示，費時費力。2023 年，一種叫做 **GCG（Greedy Coordinate Gradient，貪婪座標梯度）**的方法把越獄自動化了：它在問題末尾附加一段看似亂碼的「對抗性後綴（adversarial suffix）」，讓模型的安全機制失效。

問題是，GCG 太慢了。要成功越獄一個模型，GCG 平均需要評估約 **256,000 次**候選後綴，計算成本極高，限制了其實際應用（包括安全研究）。

## 怎麼做：找到 GCG 的三個效率瓶頸，各個擊破

研究者分析 GCG 為什麼這麼慢，找出三個根本原因：

**問題一：梯度估算不準確**

GCG 用梯度來猜「換哪個 token 能讓模型更可能說出目標回應」，但 token 空間是離散的（每個詞是一個整數編號，不像連續數值可以微分），所以梯度只是粗糙的近似。

**改良：距離正則化（distance-based regularization）**。作者發現，梯度估算誤差和 token 在嵌入空間的距離密切相關——離得遠的替換 token 估算越不準。加入距離懲罰後，選出的候選 token 更可靠。

**問題二：均勻抽樣浪費計算**

GCG 從排行前 K 名的候選 token 中均勻隨機抽樣，忽略了它們梯度大小的差異——排名第一和第 256 的候選被選到的機率一樣。

**改良：溫度控制抽樣（temperature-controlled sampling）**。類似語言模型的「溫度參數」概念，讓梯度更大的候選 token 有更高被選中的概率，減少無效評估。

**問題三：重複評估已探索的後綴**

GCG 大約有 6% 的評估預算浪費在重複評估之前已測試過的後綴。

**改良：已訪問後綴標記（visited-suffix marking）**。用一個集合記錄評估過的後綴，遇到重複直接跳過。

## 結果：8 倍效率提升，更高越獄成功率

Faster-GCG 只需 **32,000 次評估**（GCG 的 1/8），牆鐘時間（wall-clock time）縮短 7 倍。

在五個主流對齊 LLM 上的平均越獄成功率：**78.1%**，優於現有所有白盒越獄方法。針對 Qwen3.5-4B 模型更達到 **88.7%** 的成功率。

## 做不到的地方

- 屬於「白盒攻擊」——需要完整存取模型的梯度信息，對只提供 API 介面的閉源模型（如 GPT-5）無法直接應用。
- 越獄成功率高但不是 100%，特別是對更大、更強的模型效果下降。
- 論文主要測試的是較小規模的模型（如 Qwen3.5-4B），在更大規模模型（如 70B+ 參數）上的效果未被全面評估。

## 圖解

![GCG（上）與 Faster-GCG（下）的優化流程比較](assets/articles/2410.15362v2-fig1.webp)

兩個流程圖對比了舊版 GCG 和改良版 Faster-GCG 的差異。**GCG（上）**：計算梯度 → 均勻抽樣候選後綴 → 評估全部 → 選最佳替換，重複迭代。**Faster-GCG（下）**：計算梯度加距離懲罰 → 溫度控制抽樣（更智慧選候選）→ 先查已評估記錄（過濾重複）→ 評估剩下的候選 → 選最佳替換。多出的兩個機制（記錄過濾、溫度抽樣）是效率提升的關鍵。

## 怎麼看這件事

這篇論文做的是「紅隊測試（red-teaming）」研究——不是教人怎麼攻擊，而是讓 AI 開發者清楚地看到目前安全對齊的漏洞有多大。一個本來要花幾天運算的攻擊，現在幾小時就能完成，意味著安全防線需要更快速地迭代。

Faster-GCG 本質上是一個「更有效率的錯誤測試工具」。正如壓力測試讓橋樑設計更安全，這類研究讓 LLM 的對齊訓練不得不認真面對越獄攻擊的存在——而不是假裝問題不在那裡。
