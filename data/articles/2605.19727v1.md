# 在一張坦克照片上點一個輪子，AI 就在 3D 模型上指出對應的位置——這篇怎麼辦到的？

> 原始論文：Tango3D: Towards Alignment for Global and Local 2D-3D Correspondence
> 作者·單位：Zebin He、Mingxin Yang、Shuhui Yang、Hanxiao Sun、Xintong Han、Chunchao Guo、Wenhan Luo（香港科技大學 HKUST、騰訊混元 Tencent Hunyuan）
> arXiv：2605.19727v1 ・ 分類：cs.CV

一句話說重點：研究者讓 AI 不只認得「這張 2D 照片畫的東西跟哪個 3D 模型是同一件物品」，**還能指出 2D 照片上的每一個像素，對應到 3D 模型上的哪一個點**——例如你在照片上的車輪一指，AI 就在 3D 模型的車輪位置標一個紅點。這在過往的 3D 基礎模型上做不到。

---

## 背景：3D 模型「找得到」但「對不準」

過去幾年「**3D 基礎模型**」紅起來——讓 AI 看一個 3D 物件（點雲）就能理解它是什麼。實作上多半是「**把 3D 物件對齊到 CLIP 這種 2D 圖文模型的特徵空間**」。CLIP 是個強大的視覺-語言模型，能把圖片和文字嵌入同一個語意空間。

這套做法可以做「**整體檢索**」——拿一張椅子的照片，從 3D 模型庫找出對應的 3D 椅子。但有個根本限制：**它把整個 3D 物件壓成一個向量**。意思是「整件物品大概是椅子」這層資訊有，但「**這張照片上的椅子腳對應到 3D 模型的哪個區域**」這層細粒度資訊就丟了。

而後者（**像素對點的密集對應**）才是真正高階的 3D 應用所需的——3D 局部編輯、3D 零件分割、AR 物件追蹤、零售 try-on、機器人抓取，都需要知道「2D 看到的這個位置，對應到 3D 的哪裡」。

## 怎麼做：用「幾何感知」的編碼器 + 三階段訓練

研究者的方法叫 **Tango3D**，核心換掉了傳統做法的兩個關鍵元件：

**第一個換掉的：對齊錨點從 CLIP 改成 VGGT。** CLIP 的特徵空間「**只有語意、沒有空間結構**」——它知道圖中是椅子，但不太知道「椅子腿在左下角、椅背在右上角」這種空間資訊。VGGT 是另一種預訓練的 2D 視覺骨幹，**內建了幾何感**（被訓練來預測 3D 結構），所以它的 token 不只認語意還保留空間位置。

**第二個換掉的：3D 物件不再壓成一個向量。** 他們用一個預訓練的 **3D 變分自編碼器（VAE，Hunyuan3D 2.1 的編碼器）**，把點雲編碼成 **1024 個 3D token**，每個 token 對應點雲的一個區域。

兩邊都變成「**一堆 token 而非單一向量**」之後，就能把它們映射到同一個 1024 維共享空間。系統同時訓練兩個目標：

- **局部分支（local branch）**：用對比學習讓「同個位置的 2D 像素 token」與「3D 區域 token」在共享空間中靠近，不同位置的拉遠——這就是支援像素對點檢索的關鍵。
- **全域分支（global branch）**：把所有 token 池化（pool）成單一向量，做整體物件檢索。

**第三招：三階段漸進訓練。** 同時學「細的密集對應」跟「粗的整體語意」會打架。他們先讓模型專心學細粒度幾何對應、再加入全域語意、最後在更高解析度上同時精修兩者。

![圖：細粒度局部對齊範例。第一列「2D to 3D Query」：在 2D 照片上用紅色十字標一個點（如玩具人偶的手、車輛輪胎、弓箭手的箭、鱷魚的腳），AI 在對應的 3D 模型上標出紅點。第二列「Cross-case Query」：跨個體查詢，例如在第一個機器人圖上的某個部位指一下，AI 就在不同造型的機器人 3D 模型上找出對應部位（鈴鐺的同個位置在不同造型鈴鐺上）。第三列「3D to 2D Multi-view Query」：反過來，在 3D 模型上點一個位置（如坦克的砲管），AI 在不同視角的 2D 圖上標出對應點。](assets/articles/2605.19727v1-fig1.webp)

這張圖示意三種能力。**第一列**展示了「指圖找 3D」：你在 2D 照片上點任何一個位置，模型在對應 3D 物件上指出同個語意位置。**第二列**最厲害——你在某隻機器人的手上點一個位置，模型能在「**完全不同造型的另一隻機器人**」3D 模型上指出「手」的對應位置；鈴鐺的鈴環在不同鈴鐺造型上都能正確配對。這代表模型學到的不是「死記某個物件的座標」，是**「**手**」「**鈴環**」這種語意概念與幾何位置的綁定**。**第三列**展示反向：給定 3D 模型上的一個點，能在不同視角的 2D 圖上找到對應像素。

## 結果

- **像素對點對齊準確度**：在 top-5 候選中找到正確點的機率達 **約 84%**，top-10 達 **約 87%**；在自家定義的測試協議上比 VGGT 基線高約 5–12 個百分點。
- **物件整體檢索**：在 image-to-shape 和 shape-to-shape 的檢索任務上，分數和現有「只做整體檢索」的最佳方法可比（沒贏，但**沒因為加了細粒度功能就退步**）。這是論文最有意義的點——同時有兩種能力，過往的 3D 基礎模型只有其中一種。

## 做不到的地方

- **物件級而非場景級**：目前只測試在單個獨立物件上的對齊。對於整個房間、戶外場景的 3D 對齊，這套設計還沒驗證。
- **依賴一個訓練好的 3D VAE**：性能會被 VAE 的能力上限約束。換不同類型的 3D 資料可能需要重新訓練 VAE。
- **整體檢索沒贏只是「持平」**：論文用「competitive」這個字，意思是「**沒贏到 SOTA，但沒輸太多**」。對只關心整體檢索的場景，沒有純粹優勢。

## 怎麼看這件事

**為什麼值得在意？** 「**從圖片上的一個點，找到 3D 上的對應位置**」聽起來像小事，實際上是 AR、VR、3D 互動、機器人感知、3D 編輯等一大堆下游應用的基礎能力。過往 3D 基礎模型只能告訴你「是同個物品」，這篇是把粒度推進到「**像素級對應**」的代表作之一。

**哪裡該保留懷疑？** 這仍是「在乾淨的合成 3D 物件上跑」的研究，距離「真實場景、雜亂環境、實物掃描」還有距離。**整體檢索沒贏現有方法**這點也說明，為了支援細粒度對齊，模型在整體理解上做了取捨。

**怎麼理解這個方向？** 這代表 3D 基礎模型正從「**整體理解**」走向「**結構對齊**」這個新階段——和 2D 影像領域早年從「圖片分類」走向「物件偵測」、「語意分割」是類似的脈絡。背後的技術趨勢是「**用幾何感知的 2D 模型（VGGT）取代純語意模型（CLIP）當錨點**」，這可能成為下一代 3D 基礎模型的設計範式。
