# Transformer 的注意力機制藏著兩套大腦，拆開後能省下一半算力

> 原始論文：The Routing and Filtering Structure of Attention
> 作者·單位：Shafayeth Jamil、Rehan Kapadia（南加州大學電機與計算機工程系）
> arXiv：2605.18826v1 ・ 分類：cs.LG / cs.AI

一句話說重點：Transformer 注意力機制裡的 QK 矩陣其實同時做兩件不同的事——「訊息路由」和「相關性過濾」——把它們拆開後，前幾層可以用便宜得多的線性運算取代，且損失極小。

---

## 注意力機制的「黑盒」裡藏著什麼？

現代 AI 語言模型的核心是注意力（attention）機制，它讓每個詞能夠「看到」序列中其他詞。在實作上，這靠一個 QK⊤ 矩陣完成：Q（Query，查詢）乘以 K（Key，鍵值）的轉置，形成一個記錄每對 token 互相關注程度的分數矩陣。

但這篇論文發現：**這個矩陣其實在同時做兩件完全不同的事**，而且這兩件事從來沒有被明確分開過。

**第一件事：過濾（Filtering）**
對稱成分 F[i,j] = (A[i,j] + A[j,i]) / 2，表示兩個 token 的「相互相關性」——如果 token i 覺得 token j 重要，token j 也會同樣覺得 token i 重要。這像一個雙向的相關性閘門，決定哪些位置彼此相關。

**第二件事：路由（Routing）**
反對稱成分 R[i,j] = (A[i,j] − A[j,i]) / 2，表示「方向性的訊息流動」——token i 比 token j 更傾向接收 token j 的訊息（或反過來）。這像一個有方向的訊息傳遞，把資訊從源頭搬到目的地。

## 怎麼做：分解 1776 個注意力頭，設計「S-D 注意力」

研究者對 GPT-2（三種規模）、BERT-base、Pythia-410M 共 1776 個注意力頭做了分解分析，發現：

- **過濾主導路由**：GPT-2 Large 只有 48/720 個頭是以路由為主，其餘 94% 都是過濾佔主導
- **路由實際上低秩**：在真實文本上，路由成分的有效秩（effective rank）只有 2 到 5，但權重核本身的秩是 2 到 7 倍大——代表大量容量被浪費
- **標準注意力動態不穩定**：1776 個頭全部有不穩定的特徵值（Re(λ) > 0），靠層正規化（layer normalization）強制壓制

為了讓路由和過濾能夠自由組織，研究者設計了**S-D 注意力**：將 QK⊤ 替換成 L = S − D，其中：
- S 是學習到的反對稱（skew-symmetric）矩陣，對應路由
- D 是學習到的正對角（positive diagonal）矩陣，對應過濾

這個設計從數學上保證所有特徵值的實部 ≤ 0（穩定），**完全不需要層正規化就能訓練到 355M 參數**。

當路由和過濾分開、且移除層正規化後，路由自發組織成一個**「譜級聯（spectral cascade）」**：
- 第一層：路由有效秩 ≈ 2（只有一個旋轉平面，廣播性路由）
- 越深的層：路由秩越高，處理更複雜的方向性訊息流

## 結果

這個級聯揭示了「哪些層可以線性化」：

- 125M S-D 模型前 7 層（共 12 層）可以用線性注意力替換，困惑度（perplexity）只上升 < 5%
- 同樣操作在標準注意力下，第 3 層就已崩潰（困惑度暴增）
- 用 ELU+1 線性注意力替換前 4 層，困惑度只比基準高 1.4%
- 設計「級聯配置」架構（根據秩分配注意力參數）可省下 47%-65% 的注意力參數，代價是困惑度增加 3.9%-8.4%

## 做不到的地方

- S-D 注意力的對角矩陣 D 只有一個數值per頭，這讓過濾的表達力大幅受限；論文也承認這讓大型模型的語言模型能力有所下降
- 目前實驗最大只到 355M 參數，對 GPT-4 等規模（數百億）的適用性未知
- 線性化的結論依賴 S-D 注意力的分析，但標準 Transformer 直接線性化某些層能否達到相同效果，尚未充分對比
- 路由「低秩」的觀察是否足以說明那些路由容量是真正被浪費，或者只是沒在短文本上使用，仍有爭議

## 怎麼看這件事

「注意力做了兩件事」這個觀察本身很有趣，而且能產生可操作的結論（哪些層可以線性化）——這是比純分析論文更有價值的地方。如果這個方向能在更大模型上得到驗證，對於設計「混合線性-二次注意力」架構（如現在流行的 Mamba/Gemma 混合模型）可能提供更有原則性的設計指導，取代目前「靠搜索找比例」的方法。
