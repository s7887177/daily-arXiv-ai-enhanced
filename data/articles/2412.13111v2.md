# 教 AI 跳新動作的最大瓶頸是「3D 動作捕捉」太貴——這篇直接用網路上的 2D 影片解決

> 原始論文：Motion-2-to-3: Leveraging 2D Motion Data for 3D Motion Generations
> 作者·單位：Ruoxi Guo、Huaijin Pi、Zehong Shen、Qing Shuai、Zechen Hu、Zhumei Wang、Yajiao Dong、Ruizhen Hu、Taku Komura、Sida Peng、Xiaowei Zhou（浙江大學、Deep Glint、香港大學、深圳大學）
> arXiv：2412.13111v2 ・ 分類：cs.CV／cs.GR（電腦圖學）

一句話說重點：要讓 AI 從文字生成 3D 人體動作（例如「踢足球」「爬行」），現有方法都需要昂貴的 3D 動捕資料，動作種類因此非常有限；這篇把網路上海量的 2D 人體影片變成「先學 2D 動作再升維到 3D」的訓練資料，讓 AI 能生出大量訓練資料裡從沒看過的動作，例如「邊踢邊顛球」。

---

## 背景：3D 動作捕捉資料的天花板

「**文字生 3D 動作**」是電影、遊戲、VR 產業的剛需——輸入「一個人邊走邊揮手」，AI 直接吐出該動作的 3D 骨架序列，省去動畫師逐幀手刻。這個領域近年很熱，但有個天花板：**幾乎所有訓練資料都來自 3D 動作捕捉系統**（演員穿滿身反光標記，在多攝影機環境下拍攝），例如 HumanML3D、AMASS 這些經典資料集。

3D 動捕的問題：
1. **採集成本極高**：需要專業棚、多台高速相機、標記服、後製人員。
2. **動作種類有限**：常見的走、跑、跳、揮手等動作 OK，但**冷門動作（顛球、跳水、武術、街舞）幾乎沒涵蓋**。
3. **無法反映真實世界分佈**：棚拍環境太人工，真實生活中的隨意動作（坐地上、爬行、自然的對話手勢）資料極少。

因此即使 AI 模型再好，**生出來的動作種類就被資料拖死**。

對比之下，**網路上的人體影片**（YouTube、Bilibili 等）幾乎用之不竭：跳舞、體操、運動、勞動、武術、表演——什麼風格都有。可是它們是 **2D 影像，沒有真實 3D 座標**——AI 怎麼從 2D 影片學 3D 動作呢？

過去也有 MAS、TENDER 等方法嘗試這條路，但只能生**沒有全身位移的局部動作**（站著揮手 OK，但跑動、爬行不行），而且不支援文字控制。**這篇要做的，就是讓 AI 既能從 2D 影片學動作、又能用文字控制、且能生有真實位移的完整 3D 動作**。

## 怎麼做：把 3D 動作生成「降維」成多視角 2D 動作生成

作者提出 **Motion-2-to-3** 的核心觀念：**與其直接從 2D 升維到 3D（很難），不如先讓 AI 生「多個視角的 2D 動作」，再用幾何方法（三角測量）合成 3D**。

![論文 Figure 1：方法核心概念。(a) 左邊三張是從網路抓的真實影片，提取出 2D 動作；作者把 2D 動作拆成「2D Local Motion（局部關節動作，藍色框）」和「2D Root Velocity（根點速度，橘色框）」兩個獨立成分，這樣可以避開「相機運動和身體運動糾纏」的問題。右上、右下：生成的範例——「一個人走然後爬行」是 in-distribution 但 FID 比舊方法低；「一個人顛球並踢球」則是訓練集從未見過的 out-of-distribution 動作。](assets/articles/2412.13111v2-fig1.webp)

讀這張圖時，要注意三個關鍵點：

- **左邊（2D 動作來源）**：從網路影片抓骨架點，得到一段 2D 動作。
- **中間（動作表徵的拆分）**：作者把 2D 動作拆成兩部分——**局部關節動作（Local Motion）**指每個關節相對於根點的位移，**根點速度（Root Velocity）**指人在畫面中的整體移動速度。這個拆分是論文最核心的洞見。
- **右邊（3D 動作 + 文字控制）**：經過多視角生成 + 三角測量後，輸出 3D 動作；右側兩個小框展示對「分佈內」與「分佈外」prompt 的處理結果。

### 為什麼要拆「局部動作」和「根點速度」？

關鍵問題是：**真實 2D 影片裡，「相機在動」和「人在動」是混在一起的**。例如鏡頭跟著跑步的人移動，2D 上看起來人沒在動，但其實人是在跑。如果直接把 2D 動作當作 3D 動作的近似，會學到完全錯的事。

作者的解法：**只用「局部關節動作」訓練主要的 2D 動作生成器**——因為每個關節相對於根點（通常是骨盆）的相對位置不受相機運動影響，**這部分可以直接從 2D 影片穩定學到**。至於「根點速度」這部分，他們用 3D 動捕資料（HumanML3D）合成「多視角投影」當訓練資料補上。

### 兩階段訓練

1. **第一階段（單視角 2D Motion Diffusion）**：在大量網路影片提取的「文字-2D 動作」配對上，訓練一個 transformer-based 擴散模型，學會從文字生 2D 局部動作。這一階段**只用 2D 資料**，把「動作風格與多樣性」灌進模型。

2. **第二階段（多視角 Multi-view Diffusion）**：在 transformer 層之間插入一個「**view attention layer（視角注意力層）**」，讓四個視角能彼此通訊、確保一致性。然後用 3D 動捕資料 fine-tune——把 3D 動作投影成 4 個視角的 2D 動作當訓練樣本。同時加一個「**root velocity head**」預測每個視角的根點速度。

### 推論時：多視角 2D → 3D

給定一段文字，模型同時生 4 個視角的 2D 動作（含根點速度）。然後用經典電腦視覺的「**三角測量（triangulation）**」從多視角 2D 反推 3D 關節座標，再把多視角的根點速度平均累積成全域軌跡，組合成最終的 3D 動作序列。

## 結果：在訓練集動作上 FID 更低，且能生新動作

實驗在 HumanML3D 標準基準上，主要看兩個面向：

1. **In-distribution（訓練分佈內的動作）**：FID（Fréchet Inception Distance，越低越好，衡量生成與真實的差異）優於只用 3D 資料訓練的 baseline。論文宣稱 2D 資料幫助 AI 學到更精細的局部動作先驗，所以即使在 3D 動捕涵蓋的動作上也能生得更逼真。
2. **Out-of-distribution（OOD，訓練集沒看過的動作）**：這是本篇真正的亮點。**用文字 prompt 描述 3D 動捕資料完全沒涵蓋的複雜動作**（例如「邊顛球邊踢」、「邊走邊爬」），Motion-2-to-3 能生出合理的動作；傳統只用 3D 資料訓練的方法則只能生勉強相關的近似動作或乾脆崩潰。

## 做不到 / 沒解決的地方

1. **三角測量精度有限**：從多視角 2D 反推 3D 是個古典問題，**遮擋、自交、姿態歧義會導致 3D 結果不夠平滑**。論文沒詳細討論這部分的退化。
2. **2D 姿態提取仰賴現有偵測器**：訓練資料的品質受限於 2D 姿態偵測器的準確度——**對遮擋、極端視角、極端服裝（蓋住關節的長袍、太極服）的偵測誤差會傳遞到動作模型**。
3. **手部與精細表情未涵蓋**：論文聚焦全身大關節，**手指動作、面部表情、布料動態都沒處理**——對遊戲與電影的「最後 20% 品質」還有距離。
4. **多人互動未涵蓋**：訓練只看單人動作，**對「兩人對打」「群舞同步」這類互動場景的能力沒展示**。
5. **「分佈外」評估缺標準**：OOD 動作沒有真值可比對，論文展示的多是定性案例（影片或截圖），**沒有量化的「OOD FID」指標**——所以「能生新動作」的紮實度比較難審視。
6. **計算成本未量化**：擴散模型 + 多視角 + transformer attention 的組合不便宜，**生成單段動作的延遲沒在主文揭露**。
7. **與最新 LLM-based 動作生成方法的比較有限**：未跟 MotionGPT、MotionStreamer 等近期方法在同一基準完整對打。

## 怎麼看這件事

**為什麼值得在意？** 「資料瓶頸」是現在 AI 生成領域最普遍的卡點——大模型已經很強，但缺好的訓練資料就推不動下一步。對 3D 動作生成而言，「**用網路 2D 影片補 3D 動捕的不足**」這條路非常自然，但執行上的關鍵是怎麼處理「相機運動 vs. 身體運動」的糾纏。作者的「局部動作 + 根點速度」分離設計是個漂亮的工程解，**未來很可能成為這類 2D-to-3D 升維任務的標準操作**。

**哪裡該保留懷疑？** 「OOD 能力強」是本篇最賣力推銷的點，但這部分的證據主要是定性展示（看起來像在踢球），**缺少嚴格的量化基準**。觀察者很容易被「AI 居然會做這個」的新鮮感打動，但實際品質（動作是否物理合理、是否有穿模、是否流暢）需要更系統的評估。另外，**3D 動作生成的真正應用（電影／遊戲）對品質的要求遠高於學術 FID 指標**——這條路要從學術 demo 變成可用工具，可能還需要 1-2 個版本。

**怎麼理解這個研究方向？** 這代表 3D 生成正在學會「**從 2D 大資料借力**」的範式，跟 2D 圖像生成領域早期 Zero-1-to-3、Magic3D 等用 2D 擴散先驗訓 3D 物件生成的思路相通。差別在於人體動作有時序，比靜態物件複雜得多。這個方向未來能擴展到動物動作、表情、手部、多人互動，每一塊都是「有大量 2D 影片但缺 3D 動捕」的場景——同一套框架理論上都能套用。長期看，AI 動作生成從動畫師工具走到「真實創作者輸入文字就能拍片」的目標，2D-to-3D 這條路徑會是關鍵基石。
