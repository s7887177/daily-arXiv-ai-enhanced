# 緊急情況下闖紅燈對嗎？這個認知架構讓 AI Agent 學會合理違規

> 原始論文：PAVE: A Cognitive Architecture for Legitimate Violation in Generative Agent Societies
> 作者·單位：Ahmad Yehia、Abduallah Mohamed、Kun Qian、Tianyi Wang、Jiseop Byeon、Omar Hassanin、Christian Claudel（德州大學奧斯汀分校 / Meta Reality Labs / 卡加利大學）
> arXiv：2605.19351v1 ・ 分類：cs.MA, cs.AI, cs.CL

一句話說重點：AI Agent 在虛擬城市中學會了在火災逃生時「合理地」闖紅燈，在有警察監管時順從規則，在同伴違規時堅守準則——這是因為研究者給了它一套四模組的認知框架 PAVE。

---

## 問題：AI Agent 懂得什麼時候「該」打破規則嗎

通用語言模型（LLM）驅動的生成式 AI Agent 在模擬人類社會行為上已有不錯的表現——在 Smallville 這類虛擬小鎮中，Agent 能組織社交活動、傳播規範、維持合作關係。

但現有的 Generative Agent 研究幾乎全聚焦在「**合規與合作**」，幾乎沒有研究「**當規則本身應該被暫時擱置**」的情況。

例如：火災疏散時，自動駕駛 AI 應該闖紅燈逃命，還是等綠燈？在交警在場時，即使旁邊所有人都在違規，AI 應該跟著違規嗎？或者：急救人員搶行該如何對待？

這類「**合理違規（legitimate violation）**」——必要時、有比例原則地、暫時打破某條規則——正是 PAVE 要解決的問題。

## 方法：PAVE 四模組認知架構

PAVE（Perception, Assessment, Verdict, Emulation）是一個四模組框架：

**Perception（感知）**：結構化地提取情境——明確標記權威距離（有沒有警察在場？距離多遠？）、周圍同伴行為（別人在闖紅燈嗎？）、緊急嚴重程度（火災距離多近？）。

**Assessment（評估）**：沿五個維度打分，包括「合法性判斷」——明確檢查這次違規是否符合「必要性（necessity）」、「比例原則（proportionality）」、「無其他替代方案」。產生一個合法性分數 ℓ。

**Verdict（判決）**：設有一個**合法性門檻**。若 ℓ 超過閾值才允許違規；警察在場可強制覆蓋（即使合法性分數高，有警察就必須遵守）。門檻依角色個性設定不同（膽大/保守）。

**Emulation（效法）**：Agent 目睹他人違規後，根據後果更新自己的評估，而不是盲目跟從。

實驗在 **VOVILLE**（基於 Smallville 改寫的磁磚式交通環境）中進行，設計三個場景：緊急疏散違規、警察權威抑制、同伴傳染。測試四個 LLM 後端（GPT-4o、Claude、Qwen 等），以及消融研究（拿掉合法性門檻）。

## 結果

PAVE Agent 同時滿足四個性質：
1. **合理違規**：只在觸發條件（如火災）下違規
2. **服從權威**：交警在場時，即使合法性分數高，也選擇遵守
3. **範疇限制**：只違反被觸發條件所針對的那條規則（不會順便其他也違了）
4. **回復基準**：觸發條件消失後，回到遵守規則的基準行為

相比之下，沒有合法性門檻的「vanilla」Agent 失敗：要麼在緊急時刻仍盲目遵守規則，要麼一遇到同伴違規就跟著違。人工評估員也認為 PAVE Agent 的決策更「合理可信」。

## 做不到的地方

- 模擬環境為磁磚式 2D 交通場景，現實世界的複雜情境（模糊威脅、多個並發緊急情況）無法直接對應
- 合法性閾值是角色設定的靜態參數，真實人類的判斷動態性更強
- 測試只針對交通/疏散場景，是否能推廣到其他倫理困境（醫療、法律等）尚未驗證
- 依賴 LLM 後端的推理能力，不同模型下效果有差異

## 怎麼看這件事

「AI 什麼時候應該打破規則」是 AI 倫理中最難的問題之一。PAVE 的設計思路是讓 Agent 有結構化的「倫理判斷流程」，而不是讓模型自由回答「我覺得可以/不可以」。

把「合法性門檻」設計成**硬性閘門**（而非只是影響分數的一個因子），是個有趣的工程選擇——它讓行為變得可解釋和可控。不過，「必要性、比例原則、無其他替代方案」這三個評估標準的具體量化，仍依賴 LLM 自身的理解，本質上是用語言模型來評估語言模型的判斷，存在循環性。

對做 AI Agent 安全和社會模擬的研究者，這篇論文提供了一個具體可操作的框架；對普通讀者，它的價值在於提醒：讓 AI 「學會遵守規則」只是第一步，「懂得何時必須打破規則」同樣是安全 AI 不可迴避的課題。
