# 教 AI 看影片就「腦補」對方下一刻會怎麼難過，再回頭判斷情緒

> 原始論文：AffectVerse: Emotional World Models for Multimodal Affective Computing
> 作者·單位：Bo Zhao、Fanghua Ye（大灣區大學、騰訊）、Yixin Ji（騰訊）、Sicheng Zhao（清華大學）、Xiaojiang Peng（深圳技術大學）、Zitong Yu（大灣區大學）
> arXiv：2605.19950v1 ・ 分類：多模態 AI・情感運算

一句話說重點：人類判斷別人情緒時，會本能「預想」對方下一秒可能會怎麼變化（笑會繼續還是僵掉？聲音抖會更抖嗎？）；這篇研究第一次把這個「想像下一刻」的機制塞進大型多模態 AI，讓它在判斷情緒前先預測未來幾秒的語音與畫面，再回頭做判斷，在九個基準上都贏過現有方法。

---

## 背景：為什麼 AI 看影片猜情緒會卡關

想像面試官在看求職者：嘴角上揚但顫抖、聲音壓得太穩。人類觀察者不會等到對方說完，**腦袋裡會自動「演算」對方接下來可能怎麼變化**——是越來越緊張還是漸漸放鬆？這種「**預測式情緒推理**」(predictive emotional inference) 在情感科學裡有大量證據。

但目前的 AI 模型不是這樣做的：
- **傳統 CNN**：直接吃整段完整影片，匹配「這像哪一種情緒」的圖樣。
- **多模態大語言模型（MLLM）**：把影片、聲音、文字編碼後送進語言模型，靠它的通用推理能力分類。

兩者都把「情緒辨識」當成「對完整片段的靜態模式比對」——把**情緒的動態演進（升溫、緩解、跨模態衝突）壓成一張快照**。可是真實的情緒分析往往要看「它怎麼變」而不是「它現在是什麼樣」。

## 怎麼做：給 AI 裝一個「情緒世界模型」

作者的核心點子是借鑑強化學習裡的「世界模型」(world model)——讓代理人在做決策前先「想像」環境會怎麼演變。但情緒辨識沒有「動作」、「獎勵」、「規劃」這些東西，所以他們設計了「**無動作版本**」(action-free)，只負責預測未來的隱藏表徵，不做控制。

這套系統叫 **AffectVerse**，建在開源多模態模型 Qwen2.5-Omni 之上，加上一個「**情緒世界模組**」(Emotion World Module, EWM)，內含三個子模組：

1. **跨模態時間想像（Cross-Modal Temporal Imagination）**：給模型「過去幾秒」的影片與聲音 token，要它預測「接下來幾秒」的影片與聲音 token 應該長什麼樣。這個預測**只發生在隱藏表徵層**，不需要真的生出未來的影像或聲音。
2. **MAMA 信念聚合（Modality-Aware Multi-step Attention）**：把上一步「想像出來」的多個未來 token 壓縮成幾個「信念 token」(belief tokens)，代表「模型目前對未來發展的判斷」。
3. **信念注入（Belief Injection）**：把信念 token 塞回 LLM 的輸入序列裡，讓 Qwen2.5-Omni 在做最終情緒推理時，既能看到「實際觀察到的證據」，也能看到「對未來的想像」。

關鍵設計：**這個「想像」只在訓練時當作自監督訊號**——預測未來只是讓模型學會「在現在的表徵裡編碼出對未來變化有用的線索」。**推論時並不需要看到真正的未來**，模型用的還是當下的觀察，只是這個觀察的表徵已經內含了動態變化的線索。

## 結果

![AffectVerse 整體架構：(a) 上半為總覽，多模態輸入經 Qwen2.5-Omni 編碼後切成「過去/未來」，過去 token 送入跨模態時間想像 → MAMA 信念聚合 → 信念注入，最後與文字 token 一起回到 LLM；(b)(c)(d) 三個子模組的細部結構：時間想像分影片與聲音兩條分支多步 rollout，MAMA 用學習式查詢把想像 token 聚合成信念 token，最後信念注入到 LLM token 序列的兩個位置。](assets/articles/2605.19950v1-fig1.webp)

這張圖把 AffectVerse 的完整工作流程攤開來。上半部 (a) 的五個步驟順序：(1) 多模態 token 經模態特定降投影；(2) 切成「過去」與「未來」段；(3) 跨模態時間想像對未來做多步 rollout；(4) MAMA 模組把想像出來的 token 聚合成緊湊的信念 token；(5) 信念注入回到 LLM 串流。下半部 (b)(c)(d) 是三個子模組的細節——值得注意的是 **(b) 的兩條分支分別處理影片與聲音的時間想像**，這呼應了「跨模態」這個關鍵字：模型可以從聲音裡的線索想像未來的表情變化，反之亦然。

在 9 個情緒辨識基準上，AffectVerse **至少比現有最佳方法多 2.57% 的準確率**。控制變因消融顯示：時間想像、跨模態 rollout、信念聚合三者都有獨立貢獻。

## 做不到的地方

- **只做「短期未來」想像**：模組設計處理的是幾秒尺度的情緒動態，對「整段對話的情緒走勢」這種長尺度任務沒探討。
- **限定在 Qwen2.5-Omni 上**：作者只在這一個基底模型上實驗，這套 EWM 模組是否能無痛移植到其他 MLLM 沒驗證。
- **基於既有資料集評估**：「九個基準上贏過 2.57%」是 in-domain 提升，對真實世界的零樣本場景（如非英語面試、跨文化情緒）泛化能力未測。
- **訓練成本上升**：跨模態想像 + 多步 rollout 都是額外計算，論文未明確報告訓練時間與資源開銷。

## 怎麼看這件事

**為什麼在意？** 情緒辨識是人機互動、心理健康輔助、客服自動化、面試評估等應用的核心能力。如果模型能更貼近人類的「預測式」推理方式，在「片段不完整」或「情緒正在變化」的場景會更實用。

**哪裡該保留懷疑？** 「情緒」本身是個高度主觀且文化相關的概念。實驗室基準上的提升不代表在真實應用會準——尤其是在跨文化、長對話、有遮蔽（戴口罩）等情境。另外要注意：情緒辨識 AI 一旦進入 HR、保險、執法等場景，**錯誤判斷的社會代價可能遠大於準確率上的小數點提升**。

**怎麼理解這個方向？** 這篇代表「**把人腦的預測機制顯式寫進 AI 架構**」這條路線的延伸。從 LLM 的 chain-of-thought 到視覺生成的世界模型，再到這篇的情緒世界模組，趨勢都是「不要只反應、要先想像再決定」。未來可能會看到「對話世界模型」、「協作世界模型」等類似結構出現在更多任務上。
