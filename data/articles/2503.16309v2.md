# 開刀房裡的 X 光跟術前 3D 掃描對不上？這套 AI 五分鐘給每個病人量身打造一個模型

> 原始論文：Rapid patient-specific neural networks for intraoperative X-ray to volume registration
> 作者·單位：Vivek Gopalakrishnan、David-Dimitris Chlorogiannis、Andrew Abumoussa、Anna M. Larson、Nazim Haouchine、Darren B. Orbach、Sarah Frisken、Neel Dey、Polina Golland（MIT CSAIL／Harvard-MIT 健康科學與技術、Harvard Medical School、Boston Children's Hospital 等）
> arXiv：2503.16309v2 ・ 分類：eess.IV（生醫影像）／cs.CV／physics.med-ph

一句話說重點：手術中常會邊開刀邊照 X 光定位器材，但 X 光是 2D 平面像、術前的 CT/MRI 是 3D 立體像，兩者怎麼準確對齊一直是難題；這篇做了一套叫 xvr 的開源系統，先用大量 CT 資料訓練一個「基礎模型」，到了個別病人時只要 5 分鐘微調，就能在手術中秒級給出 2D 對 3D 的精準對位。

---

## 背景：開刀房裡看到的影像，跟術前掃描永遠對不上

每年全球有數百萬場手術仰賴**即時 X 光導引**（fluoroscopy，俗稱「透視」）來定位器械——心導管、神經介入、骨科植入物等等都用得到。但 X 光本質上只是把 3D 身體投影到 2D 平面，**沒有深度資訊**，醫生很難精準判斷器材在 3D 體內的位置。

理想做法是：拿術前的 CT 或 MRI（3D 立體影像）和手術中的 X 光（2D 平面影像）即時對齊。**這就是「2D/3D registration」（2D 對 3D 影像配準）問題**。配準成功後，醫生在 X 光上看到的器械位置，就能對映回 3D 解剖結構，等於讓 2D 影像「擁有」立體導航能力。

但配準在臨床上一直難以普及，因為現有方法有以下毛病：

1. **傳統「強度匹配」方法**：拿 3D 體積數位重建出一張合成 X 光，跟真實 X 光比較像不像，反覆優化 C 形臂（X 光機的弧形軌道）的位姿。**問題是這種反覆優化非常依賴起始猜測**——只要起點偏差幾公分，就會卡進錯誤解。
2. **深度學習法**：訓練神經網絡直接從 X 光預測 C 形臂位姿，或先找解剖標記點再配準。**問題是要醫師手動標註大量訓練資料**，且訓練好的模型**只能用在它見過的部位**（骨盆訓練出來的不能拿來做頭頸）。
3. **半監督法**：可以把標記從舊病人轉到新病人，但仍需大量人工標註的訓練集。

要解決的核心問題是：能不能做出一個**對任何部位、任何病人、任何儀器**都能準的 2D/3D 配準系統，**而且不需要人工標註**？

## 怎麼做：用物理模擬產生「無限」訓練資料

作者提出的 **xvr** 是一套**自監督**框架，巧妙地用「**物理模擬**」取代「人工標註」。整體流程見下圖：

![論文 Figure 1（節錄前半段）：xvr 流程示意。(a) 術前用 CT 或 MRI 掃描病人取得 3D 影像。(b) 醫療團隊根據 3D 影像做診斷與規劃。(c) 作者開發了一個「可微分 X 光繪製器」，用 3D 影像虛擬重建合成 X 光，其幾何符合商用 C 形臂的座標系統（α 為左右斜角 LAO/RAO、β 為頭尾角度 CRA/CAU、y 為光源距離 SOD）。(d) 用合成 X 光訓練「病人專屬神經網路」5 分鐘，網絡從 X 光輸入預測 C 形臂位姿，再重繪一張對照，跟真值比對差異後反覆學習。](assets/articles/2503.16309v2-fig1.webp)

讀這張圖時，重點看右半部 (c) 和 (d)：

- **(c)** 給 3D 掃描影像和一組「假設的 C 形臂位姿」，系統會用一個**可微分（differentiable）的 X 光繪製器**算出「如果從這個角度照 X 光會長怎樣」。這個繪製器精確符合醫院實際用的 C 形臂幾何（α、β 兩個旋轉軸與光源-物距 y）。
- **(d)** 用這個繪製器一次產生上千張合成 X 光（**每張都自帶完美真值位姿**，因為位姿是我們自己設定的），餵給一個神經網絡學「從 X 光反推 C 形臂在哪」。預測出位姿後再用繪製器重畫一張，與原圖比對差異——這就是自監督迴圈。

### 兩個關鍵技術細節

論文強調這套設計裡兩個非顯而易見的工程選擇：

1. **網絡輸出不能直接吐角度或四元數**：因為 3D 旋轉構成的數學流形 SE(3) 不是普通歐氏空間，**四元數會有不連續處**，導致 CNN 學不會。作者改用「四元數伴隨矩陣」（quaternion adjugate，一種高階表示）來避免不連續性。
2. **網絡不能太小**：實驗發現 ResNet18 完全擬合不了大範圍位姿，**必須用 ResNet34** 才行。

### 「先大規模預訓練、再個人化微調」

為了讓任何病人都能快速套用，作者**先用四個公開資料集裡的 2,245 個全身 CT/MR 掃描**（涵蓋骨折、金屬植入、顯影增強等多種臨床情境）統一對齊到一個模板，然後訓練一個**基礎模型**：覆蓋 360° LAO/RAO 與 ±60° CRA/CAU 的位姿範圍，可以在任何 C 形臂設定下使用。

到了真實病人時，**只要用該病人自己的 CT 微調 5 分鐘**——比過去從頭訓練要花 12 小時的做法快 144 倍——就能達到相當的精度。手術中拿到 X 光時，網絡先給出初步位姿估計（秒級），再用差分式優化精修到毫米級。

## 結果：跨越多醫院、多模態都領先

作者在五個資料集驗證：
- **DeepFluoro**：6 具下半身大體的骨盆 X 光與 CT（362 張）
- **Femur**：5 具大體的遠端股骨 X 光與 CT（49 張）
- **Ljubljana**：10 位神經血管介入手術病患的 2D/3D 數位減影血管攝影（DSA）
- 兩個內部臨床資料集：成人與新生兒 CT/MR 血管攝影

關鍵發現：

- **精度比現有方法高一個數量級**：在所有資料集上 xvr 的目標配準誤差（mTRE）都顯著低於先前的（半）監督深度學習與無監督迭代法。
- **5 分鐘微調達到 12 小時從頭訓練的精度**：基礎模型的「群體先驗」非常有用。
- **跨模態泛化**：預訓練資料包含 MR 血管攝影，但拿到從未見過的「2D DSA 數位減影血管攝影」也能 work——這是介入神經外科的標準術中影像。
- **可處理術中臨床變化**：醫師在介入手術中常會調整 X 光機的視野（panning、縮放），打破訓練時的假設。作者額外設計了一個「幾何重採樣」步驟，把實際 X 光換算回標準參數，讓網絡仍能用。

## 做不到 / 沒解決的地方

1. **僅限剛體配準（rigid registration）**：xvr 假設骨骼、器官等是剛體，但**真實人體會呼吸、心跳、組織會變形**——軟組織配準需要另一套變形配準（deformable registration）方法。
2. **預訓練資料偏向特定部位**：雖然號稱「全身」，但 2,245 個 CT/MR 主要是骨科與神經血管領域，**胸腔、腹腔、心臟等動態器官未深入測試**。
3. **「特異解剖」需要從頭訓練**：作者特別提到內臟反位（situs inversus，內臟左右顛倒）等罕見解剖，基礎模型微調可能不夠，仍需從頭訓 12 小時。
4. **GPU 依賴**：5 分鐘微調是在 NVIDIA RTX 6000 Ada GPU 上達成的，**一般醫院不一定有這樣的計算資源**。對術中即時使用，需要至少一張高階 GPU 就位。
5. **未做盲式臨床驗證**：所有資料都有真值位姿（大體或追蹤系統量測），**真實活體手術中沒有真值可比對**——實際手術精度仍需未來臨床試驗驗證。
6. **大體實驗與活體之間有 gap**：DeepFluoro 與 Femur 都是大體研究，無呼吸與心跳；活體狀況下軟組織位移會引入額外誤差。

## 怎麼看這件事

**為什麼值得在意？** 即時 X 光導引是現代心血管介入、神經介入、骨科手術的基石，但「2D 影像看不到深度」這個天生限制造成了大量臨床問題（操作偏差、輻射劑量增加、手術時間拉長）。**如果 2D/3D 配準能變得即插即用，等於把現有 X 光機升級成 3D 導航系統，無需新硬體**——這對機器人手術、自動化介入工具的發展是顯著推力。xvr 把「自監督 + 物理模擬 + 個人化微調」串成一條真實可用的流程，是這個方向上的重要進展。

**哪裡該保留懷疑？** 「精度比現有方法高一個數量級」是相當大的宣稱，但要注意比較基準仍是學術方法，**沒有跟商業手術導航系統（如 Brainlab、Medtronic 等）正面對決**。另外 mTRE 動輒 30-90 mm 的初始誤差需要迭代精修才能到「臨床可用」的毫米級，**精修步驟的穩定性與失敗率沒詳細統計**。最關鍵是：**所有驗證都在「靜止」的解剖上**，真實人體會動、會呼吸、軟組織會變形，這套方法對動態場景的表現仍是未知數。

**怎麼理解這個研究方向？** 這代表手術導航正在從「特製硬體 + 大量人工標註」走向「**通用基礎模型 + 個人化微調**」這條更可擴展的路徑——和大型語言模型的發展邏輯類似。把物理模擬當成自監督的「訓練資料工廠」是個有力的範式，未來可能擴展到內視鏡導引、超音波對 CT 配準、甚至機器人觸覺校正等其他多模態醫療影像問題。作者開源整套系統，降低了臨床研究團隊的進入門檻，這對加速領域進展有實質意義。
