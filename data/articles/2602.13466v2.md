# 語言模型到底「記」了什麼？自編碼器揭示隱藏層的記憶缺陷

> 原始論文：Language Model Memory and Memory Models for Language
> 作者·單位：Benjamin L. Badger（史丹佛大學）
> arXiv：2602.13466v2 ・ 分類：cs.CL、cs.AI、cs.LG

一句話說重點：標準語言模型訓練出來的「記憶能力」其實相當有限，而自編碼器（autoencoder）的訓練目標可讓模型形成真正高保真的語義記憶，並大幅提升計算效率。

---

## 背景：「記憶」在機器學習裡一直是個模糊概念

在深度學習中，「模型記住了什麼」這件事聽起來很自然——明明我們會說 GPT「記住了大量知識」。但「記住」究竟代表什麼？更精確地說：隱藏層的嵌入向量（embedding）能從輸入訊號中還原多少原始資訊？

這個問題有實際影響。如果能把整段輸入文字壓縮成一個高品質的「記憶向量」，就可以：
- 在推論時用嵌入向量取代 Token 序列，大幅降低計算量
- 建立更有效率的長文脈絡處理機制

但事實上，沒有人系統地測量過語言模型的嵌入到底「記住」了多少原始輸入。

## 怎麼做：用解碼器來「考試」——看嵌入能還原多少原始 Token

作者設計了一套**資訊保留實驗**：
1. **凍結被測模型（編碼器）**：選擇不同訓練方式的語言模型作為編碼器。
2. **訓練可學習的解碼器**：解碼器的任務是從最後一層隱藏層的嵌入向量，還原出**完整的輸入 Token 序列**（類似填字遊戲的解法）。
3. **以還原損失衡量記憶品質**：解碼器損失越低 = 嵌入保留的輸入資訊越多；準確率越高 = 每個位置的 Token 還原越精確。

測試了五種不同的編碼器：
- **未訓練（隨機初始化）**的模型
- **因果語言模型（Causal LM）**：即標準 GPT 式「預測下一個 Token」目標訓練的模型
- **加入檢索目標（Causal → Retrieval）**的微調版本
- **自編碼器（Autoencoder）**：以重構輸入為訓練目標（類似 BERT 遮罩語言模型的極端版本）

同時在兩種模型架構（Masked Mixer 和 Transformer）上重複實驗。

## 結果

| 編碼器類型 | Masked Mixer 準確率 | Transformer 準確率 |
|---|---|---|
| 自編碼器（短上下文 256） | **99.6%** | **95.4%** |
| 自編碼器 | 91.8% | 43.3% |
| 未訓練（隨機） | 4.7% | 4.7% |
| 因果語言模型 | 5.5% | 5.0% |
| 因果 + 檢索微調 | 5.5% | 5.3% |

核心發現：
- **標準因果語言模型的嵌入幾乎不含輸入資訊**——準確率僅約 5%，與未訓練模型相當，而且不隨資料規模或計算量增大而改善。
- **自編碼器訓練能形成接近完美的記憶**，在短序列上還原準確率高達 99.6%。
- Transformer 在較長序列的自編碼記憶上比 Masked Mixer 難，顯示序列長度與架構對記憶形成有交互影響。

這個結果的含義是：**「預測下一個 Token」這個訓練目標本身是不可逆的（non-invertible）**——模型不需要記住整個輸入，只需要記住能幫助預測下一詞的部分統計資訊，自然不會形成高保真記憶。

## 新架構：平行化編碼器—解碼器記憶模型

基於上述發現，作者提出一種新型**平行化編碼器—解碼器記憶模型**架構：
- **高保真編碼器**（已訓練好，凍結）：負責把輸入 Token 序列壓縮成資訊豐富的記憶嵌入。
- **可訓練解碼器**：先學習從記憶嵌入解碼（課程學習的第一階段），再學習依此預測下一個 Token（第二階段）。
- **效率優勢**：推論時以嵌入向量取代完整 Token 序列輸入，計算量大幅降低；且因為是平行處理，沒有因果模型固有的序列延遲。

## 做不到的地方

- 自編碼器訓練需要明確的重構目標，與現有大規模語言模型預訓練範式不同，從零整合成本高。
- 在超長文脈絡（數千 Token）下，記憶向量的資訊保留度顯著下降，目前方法在長文處理上仍有瓶頸。
- 實驗使用的模型規模相對較小，大型模型（10B 以上）是否有相同的記憶缺陷特性尚待驗證。
- 「記憶保真度」的提升不一定直接等於語言模型任務（如問答、摘要）的效能提升，兩者關係還需進一步研究。

## 怎麼看這件事

這篇論文揭示了一個在機器學習社群中長期被忽視的問題：我們以為語言模型的隱藏層嵌入「記住了」輸入——但實際上，標準訓練目標根本不鼓勵模型這樣做。這不只是學術問題：如果能讓模型真正形成高保真記憶嵌入，就有機會在推論速度和長文脈絡理解上取得實質突破。雖然目前實驗規模有限，但這個思路值得更大規模的驗證與探索。
