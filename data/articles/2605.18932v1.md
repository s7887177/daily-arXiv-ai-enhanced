# 把建築格局設計交給語言模型：輕量 LLM 微調後能畫出精確平面圖

> 原始論文：HypergraphFormer: Learning Hypergraphs from LLMs for Editable Floor Plan Generation
> 作者·單位：Nikita Klimenko、Hesam Salehipour、Amir Khasahmadi（Autodesk Research）；Parham Eftekhar（約克大學）；Ramon Elias Weber（加州大學柏克萊分校建築學院）
> arXiv：2605.18932v1 ・ 分類：cs.LG / cs.AI

一句話說重點：把室內格局用「超圖（hypergraph）」的 JSON 結構描述，然後用小型 LLM 微調學習從房間連通需求直接生成這份 JSON——不需要像素或座標，平面圖就能任意編輯、能換邊界、能加減房間。

---

## 建築師設計平面圖，電腦能幫忙嗎？

設計一間公寓的格局需要在房間數量、面積分配、走廊動線、採光、建築法規之間反覆取捨。現有的自動化方法有兩條路：

- **像素遮罩方式**（如 HouseGAN）：輸出的是低解析度圖片，解析度受限，後處理繁瑣，也很難用程式修改一個房間。
- **向量多邊形方式**（如 HouseDiffusion）：預測每個房間的角點座標，但通常只支援矩形房間，牆必須與座標軸平行。

這兩種方式都有個更根本的問題：生成後幾乎無法局部修改，要改就要整個重新跑一遍。

## 超圖 JSON：讓平面圖變成「可讀的文字」

HypergraphFormer 的核心思路來自 Weber 等人先前的研究——把一間公寓的格局表示成一份**結構化 JSON**，其中包含兩個部分：

- **Access graph（門連通圖）**：節點是每個房間（臥室、廚房、客廳……），邊代表兩個房間之間有門連通。這是使用者的輸入——你說「我要三房一廳，廁所連臥室」。
- **超圖（Hypergraph）**：用二元空間分割（BSP，Binary Space Partition）樹來遞迴描述空間如何被分割成各個房間，並附上每個葉節點（房間）的面積比例和語意標籤。

這個 JSON 可以直接被程式解析和修改：想把臥室改大一點？改一個數字。想加一個浴室？在 JSON 裡插入一個節點。不需要重新生成整張平面圖。

## 方法：微調 Qwen3 學習生成 JSON

研究者用 Qwen3（一個開源的指令微調 LLM）加上 **LoRA**（Low-Rank Adaptation，低秩適應）技術，在 RPLAN 資料集（約 80 萬筆真實中國公寓平面圖）上做監督式微調。輸入：一個房間連通圖的 JSON 描述；輸出：對應的超圖 JSON。

訓練完成後，模型只需一次前向傳播就能根據使用者指定的房間需求（連通關係 + 外框邊界）生成完整格局——**外框邊界可以是任意形狀**，不限矩形。

生成的 JSON 還可以接上一套無需 LLM 的程序性編輯工具：面積最佳化（梯度下降調整房間比例）、旋轉 / 鏡像、新增或移除房間。更高階的編輯（「把廚房和餐廳合併」）則可以再呼叫 LLM 修改 JSON。

## 效能比較

在 RPLAN 測試集上，HypergraphFormer 在結構指標（房間連通圖準確率 GED）和幾何指標（面積比例誤差）上均優於 HouseGAN++、HouseDiffusion、iPlan、DiffPlanner 等基準。

更關鍵的是分佈外泛化：訓練完 RPLAN 後直接測試 WMR24（研究者自建的 24 個建築師手繪平面圖資料集，外框不規則、設計風格截然不同），HypergraphFormer 仍顯著優於所有比較方法——而其他方法的準確率大幅下跌。

資料效率測試顯示：用不到完整訓練集的一小部分，HypergraphFormer 就能達到其他方法用全量資料才達到的效果。

## 做不到的地方

- **不生成詳細施工圖**：輸出的是空間分割比例和房間標籤，並非帶有精確尺寸的 CAD 圖面，還需要下游的幾何重建步驟。
- **主要對齊軸向分割**：BSP 樹預設做軸平行切割（水平或垂直），任意角度的斜牆需要額外擴充。
- **WMR24 資料集太小**：只有 24 筆，分佈外測試的統計力有限；雖然論文已公開此資料集，但規模仍小。
- **LLM 呼叫延遲**：高階語意編輯需要再呼叫 LLM，在需要即時互動的設計工具中可能造成等待。

## 怎麼看這件事

這篇論文的聰明之處在於「不設計新模型，而是問現有 LLM 能不能學會生成一種已被設計好的結構化表示」。答案是肯定的，而且帶來了像素和座標方法無法輕易實現的可編輯性。對建築和室內設計軟體開發者而言，HypergraphFormer 展示了 LLM 在設計輔助工具中的一種實際可行路徑，值得關注。
