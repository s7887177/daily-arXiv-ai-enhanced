# 不用反向傳播也能微調大語言模型：一個尺度修正解開「秩悖論」

> 原始論文：AR1-ZO: Topology-Aware Rank-1 Zeroth-Order Queries for High-Rank LoRA Fine-Tuning
> 作者·單位：Ziye Chen, Hongbin Lin, Chenyu Zhang, Xiangda Yan, Yongjie Yang, Yao Shu（香港科技大學（廣州）等）
> arXiv：2605.19767v1 ・ 分類：cs.LG / cs.AI

一句話說重點：這篇論文找到了「零階最佳化 + LoRA 高秩微調」組合失效的根本原因，並用一個簡單的尺度修正（把縮放係數 α/r 換成 αr）讓訊號從雜訊中消滅前找回來，只需要兩次前向傳播就能微調大模型。

---

## 問題：記憶體省了，但高秩 LoRA 為什麼不管用？

微調大型語言模型（LLM）有兩條省記憶體的路：

- **LoRA**（Low-Rank Adaptation）：凍結原始模型權重，只訓練低秩的「適配器」矩陣（ΔW = γ/r × BA，B 和 A 是低秩因子），大幅減少可訓練參數。秩 r 越大，適配器越有表達能力；但 r 小就夠用的任務，r 大只是浪費。

- **零階最佳化（Zeroth-Order Optimization，ZO）**：不計算梯度，只用兩次前向傳播（一次加微擾、一次減微擾）來估計損失函數的方向，連反向傳播儲存的中間激活值都不需要，記憶體節省顯著。

兩者組合看起來是夢幻搭配，但問題出現了：**秩 r 越大，ZO 越難用**。傳統解釋是「維度詛咒」——秩大就要同時擾動更多參數，估計方差爆炸。但這篇論文指出，維度只是問題的一半，還有更根本的失效機制。

## 怎麼做：找到「訊號消失」的真正原因

研究者把問題拆解成三個獨立概念：
1. **儲存秩**：適配器的秩 r，決定表達能力。
2. **單次查詢擾動維度**：一次 ZO 查詢要同時擾動多少個座標。
3. **有限差分訊號強度（FD-SNR）**：損失差值能否從評估雜訊中分辨出來。

現有方法的錯誤是把三者綁在一起：秩大了，擾動維度也大，訊號也縮水。

**AR1-ZO 的核心洞察**：LoRA 的更新 ΔW 天然可以寫成 r 個秩-1 原子（rank-1 atom）的總和，每個原子是 (b_k, a_k) 的外積。每次只查詢一個原子，就能把「單次擾動維度」從 r(d_out+d_in) 降到 d_out+d_in，和秩 r 完全無關，同時適配器仍然是完整的秩-r 矩陣。

**但問題沒有解決完：尺度崩塌**

天真的原子查詢繼承了 LoRA 的標準縮放係數 α/r（為聯合更新所有秩設計的）。在逐原子查詢時，只有一個原子在動，但縮放分母仍然是 r，導致：
- 有效訊號縮小 1/r 倍
- FD-SNR 縮小 1/r² 倍（「方向性崩塌」，directional collapse）
- r 大到一定程度，訊號淹沒在評估雜訊底噪中，學不到任何方向

**拓撲感知縮放的修正**

只需把縮放係數從 α/r 改成 αr（即 γ = αr），就能讓每次原子查詢的有效訊號恢復到和秩無關的水準。這不是改變 LoRA 整體的縮放規則，而是針對「順序單原子查詢」的測量補償。剩下和秩有關的代價，只剩「輪流查詢所有原子所需的回合數」——這是無法避免的覆蓋成本。

## 結果

在 OPT（125M 到 2.7B）和 Qwen3 模型上，AR1-ZO 在匹配預算（同樣每步兩次前向傳播）下，讓高秩 LoRA 的效果優於傳統零階方法和低秩 LoRA，並通過 FD-SNR 隨秩的掃描實驗直接驗證了訊號機制（方向性崩塌確實存在、修正後確實消失）。

## 做不到的地方

- 相較於一階梯度方法（如 Adam），ZO 收斂速度仍然慢；AR1-ZO 是在記憶體約束下的最優化，不是無限制設定下的最優微調方案。
- 覆蓋所有秩-1 原子的成本（輪流掃描 r 個原子）隨秩線性增長，在超大秩設定下總體代價仍高。
- 理論分析假設評估雜訊有界，實際訓練環境（批量採樣雜訊、多 GPU 同步誤差）可能更複雜。
- 實驗覆蓋模型規模有限，頂尖模型（如 70B+）的效果未測試。

## 怎麼看這件事

這篇論文做了一件看起來「解法很小但問題很精準」的事：用一個無外加參數的縮放修正，解決了 ZO+LoRA 高秩組合失效的核心問題。沒有引入新的模組、外部子空間或額外的正向傳播，只是找到問題的正確框架（分離三個「秩的角色」），然後做最小的修正。

值得關注的是：大模型訓練愈來愈追求記憶體效率，ZO 方法在推論只能存 32GB 記憶體的邊緣設備、或沒有梯度訪問權限的黑箱 API 場景，都有實際意義。如果 AR1-ZO 的修正能在更大的模型和更多任務上複現，它很可能成為 ZO+LoRA 組合的標準基礎操作。
