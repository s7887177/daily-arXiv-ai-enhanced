# 訓練大語言模型不用調學習率？ScheduleFree+ 讓長訓練贏過一切

> 原始論文：ScheduleFree+: Scaling Learning-Rate-Free & Schedule-Free Learning to Large Language Models
> 作者·單位：Aaron Defazio（Meta FAIR 超智慧實驗室）
> arXiv：2605.19095v1 ・ 分類：cs.LG / cs.AI / stat.ML

一句話說重點：訓練大語言模型（LLM）時最頭痛的學習率調整問題，ScheduleFree+ 用「平均化」完全取代「排程」——訓練夠久時，比最好的現有排程方法快 31%。

---

## 問題在哪裡

訓練神經網路時，學習率（learning rate）是最關鍵也最難調的超參數之一。現在主流的做法是「排程」（schedule）：先讓學習率暖機（warmup），然後穩定訓練，最後衰減（decay）。這種「預先決定好怎麼降」的方式有個根本問題：**訓練中途停下來的模型往往表現很差**——因為排程是針對特定訓練長度設計的，沒跑完就沒辦法。

Schedule-Free Learning（無排程學習）是一個另闢蹊徑的方向：完全不用學習率排程，改用「加權平均化」讓訓練收斂。理論上更穩定，實踐上也可以隨時停下來使用已知最佳的模型。但問題是，它在大 batch size 和大模型規模下會失效。

## 他們怎麼做

這篇技術報告（tech report）識別了幾個讓 Schedule-Free Learning 在 LLM 預訓練中失效的原因，並一一修復：

1. **重新引入內層動量（inner momentum）**：原始 Schedule-Free 為省記憶體而移除了 AdamW 的動量項，但大 batch size 時這會讓訓練在學習率稍高時就不穩定。加回 β₁ ≈ 0.75 的內層動量修復了這個問題。

2. **Polyak 步長（Polyak step size）自動決定學習率**：用梯度範數的歷史 EMA（指數移動平均）估算最優步長，讓方法真正「無需手調學習率」。這給出了一個完全自適應的訓練配方。

3. **暖啟動（warm-starting）**：從已訓練的 checkpoint 繼續，而不是從頭開始，顯著改善早期訓練表現。

4. **增加外層動量（beta-annealing）**：訓練過程中漸進地提高平均化的動量係數（β 從 0.8 增至 0.965），讓長期訓練的收斂更快。

最終版本叫 **ScheduleFree+**，在 120M、250M、500M 參數的 LLM 上全面驗證。

## 結果

- **短期訓練（20–100 token/parameter）**：ScheduleFree+ 與線性衰減排程相當，無明顯優劣。
- **長期訓練（1000 token/parameter）**：ScheduleFree+ 比 WSD（Warmup-Stable-Decay）排程和線性衰減排程都快 **31%**——即達到相同損失值所需的訓練時間縮短了 31%。
- **隨時停用**：因為不依賴排程末尾的衰減階段，任何訓練中間點的模型都比傳統排程的中間 checkpoint 表現更好。
- **模型平均的理論基礎**：Schedule-Free 的平均化機制為「預訓練期間的模型平均和 checkpoint 合併」提供了數學基礎。

## 做不到的地方

- 短期訓練上沒有優勢，需要足夠長的訓練才能體現 ScheduleFree+ 的特長。
- Polyak 步長在某些設定下仍需要微調（論文承認需要選擇合適的 EMA 平滑係數）。
- 目前主要在 LLM 預訓練場景驗證，在微調（fine-tuning）或強化學習（RLHF）場景中的行為尚未深入研究。
- 單作者論文，缺乏獨立驗證；技術報告格式，不是完整的研究論文。

## 怎麼看這件事

LLM 訓練中「學習率調參」是一個真實的工程痛點：一個訓練幾周、花幾十萬美元的訓練跑，往往因為學習率沒調好而需要重新跑。任何能降低這種靈敏度的方法都有實用價值。

Schedule-Free Learning 的核心思想是優雅的：不要「計畫好學習率怎麼降」，而是讓平均化自然產生收斂。ScheduleFree+ 填補了在大規模 LLM 場景下的工程缺口。31% 的長期訓練加速是個引人注目的數字，但需要注意：這個優勢主要在「訓練夠長」時才顯現，而且只有一個作者的技術報告尚待社群獨立複現。這篇論文最可能的影響是：激勵更多研究者認真測試無排程訓練方法，而不是停留在「原始 Schedule-Free 太難調」的印象上。
