# 讓 AI 玩推箱子別再「用文字寫筆記」——改畫一張危險地圖,小模型反而打敗 GPT-5

> 原始論文：AtlasVA: Self-Evolving Visual Skill Memory for Teacher-Free VLM Agents
> 作者·單位：Pan Wang、Yihao Hu、Xiujin Liu、Jingchu Yang、Hang Wang、Zhihao Wen（螞蟻集團 Ant Group、中國科學技術大學、西湖大學、密西根大學安娜堡分校、中山大學)
> arXiv：2605.17933v1 ・ 分類：cs.CV

一句話說重點：會看圖又會動手的 AI 智能體在玩推箱子、走迷宮這類「空間任務」時,過去都把經驗寫成文字筆記、還要靠一個更強的「老師模型」來整理;螞蟻集團團隊提出 AtlasVA,改成把經驗畫成「哪裡危險、哪裡接近目標」的彩色熱度圖,不需要老師、自己從遊玩紀錄長出地圖,結果一個 30 億參數的小模型在多項測試上反而贏過 GPT-5。

---

## 背景:把「空間經驗」寫成文字,是天生不合適的

現在有一類 AI 叫「視覺語言模型智能體」(VLM agent):它能讀指令、看畫面、執行動作,適合用在需要一步步操作的環境,例如解推箱子謎題、走迷宮、控制機械手臂擺積木。這類任務常常很長、要累積經驗,不能每一步都從零想。

為了累積經驗,主流做法是給它一個「記憶體」,把過去成功/失敗的招數記下來重複利用。問題是:**幾乎所有現有系統都把記憶存成文字**,而且常常還要外掛一個強大的「老師模型」(專有 LLM)來幫忙摘要、合併、改寫這些文字筆記。

作者指出,這套做法對純語言任務還行,但對「靠空間感知做決策」的任務根本不對味,有三個毛病:

1. **模態錯配(把 2D 壓成 1D 文字)**:把一張二維地圖的格局壓成一條條文字規則,會丟掉幾何結構。死路、局部陷阱、有希望的中繼區域,用文字很難講清楚——這是「有損的翻譯」。
2. **依賴老師模型**:要靠一個專有大模型來整理記憶,既增加成本,又違背「完全自主自我改進」的初衷。
3. **稀疏的文字回饋**:用抽象的文字評語當強化學習的獎勵訊號,缺乏精確的座標資訊,讓「哪一步做對做錯」的歸因變得很難。

![Figure 1：兩種範式的對比。上半「文字中心範式」:遊戲畫面交給老師 LLM,產出「避開角落、保持中央、避開邊緣」這類文字技能,獎勵稀疏(整排格子只有少數變黃=達標),且有模態錯配、依賴老師、稀疏文字獎勵三大問題。下半 AtlasVA:直接從遊玩軌跡統計長出彩色地圖(紅=危險扣分、綠=安全加分),自我演化、不需老師、提供密集視覺獎勵。](assets/articles/2605.17933v1-fig1.webp)

這張圖把兩條路講得很清楚。**上半部(粉紅,文字中心)**:畫面丟給一個「老師大模型」,它吐出文字技能庫(「避開角落」「保持中央」「避開邊緣」),獎勵是稀疏的(下方一長排格子只有零星變黃=偶爾達標),紅框標出三大病灶。**下半部(綠色,本文 AtlasVA)**:直接從遊玩軌跡的統計資料長出一張**彩色熱度圖**(紅=危險要扣分,綠=安全可加分),形成「感知—最佳化」的閉環,自己演化、不需老師,而且每一步都有密集的視覺獎勵。

## 怎麼做:把記憶分成三層,核心是一張會自己長大的地圖

AtlasVA 的記憶(稱為視覺技能記憶 VSM)分三層,互補:

- **第一層:空間熱度圖**。在環境上鋪兩張連續地圖——「危險圖」標出會卡死的高風險區,「親和圖」標出接近完成任務的區域。關鍵是它們不存成文字陣列,而是**直接畫成 RGB 彩色熱度圖**,疊在原畫面上,讓模型一眼看出哪裡危險、哪裡有戲,不用做有損的翻譯。
- **第二層:視覺範例**。從歷史遊玩中挖出少量代表性截圖,標上「成功」或「失敗」當具體參考。
- **第三層:符號文字技能**。保留一小組高層策略文字規則(如「箱子推進兩面牆夾的角落就再也推不出來」),負責高層推理。

最關鍵的是**「無老師的地圖自我演化」**:這些熱度圖不是靠外部老師寫出來的,而是純資料驅動——把「從地圖拓撲抽出的靜態啟發」(角落死路、到目標的廣度優先搜尋距離)和「自己玩出來的軌跡統計」融合,用指數移動平均(EMA)持續更新。然後把這張演化中的地圖**當成密集的塑形獎勵**:踩到危險區扣分(危險懲罰)、靠近目標加分(親和增益),補上環境本身稀疏的獎勵。改進後的軌跡又回頭刷新地圖,形成閉環。

(訓練時會用模擬器內部的特權格點狀態來建構地圖,但實際部署時策略只看畫面;3D 連續空間會投影成 2.5D 的視覺先驗。)

## 結果:30 億參數小模型,整體贏過 GPT-5

底層用的是 Qwen2.5-VL-3B(30 億參數的小模型),用 PPO 強化學習訓練,在四類測試上評估:推箱子(SOKOBAN)、冰湖(FROZENLAKE)、3D 具身導航、3D 機械手臂操作(PrimitiveSkill)。整體成功率(Overall):

| 模型 | 整體成功率 |
|---|---|
| GPT-5 | 0.69 |
| o3 | 0.71 |
| Claude Sonnet 4.5 | 0.62 |
| Qwen2.5-VL-72B(開源大模型) | 0.55 |
| Qwen2.5-VL-3B(同底座,未加 AtlasVA) | 0.09 |
| VAGEN(強競爭基準) | 0.78 |
| **AtlasVA(本文,3B 底座)** | **0.93** |

最有說服力的對照是:**同樣是 Qwen2.5-VL-3B,沒加 AtlasVA 只有 0.09,加上後衝到 0.93**——而且在空間密集的任務上(機械手臂的擺放、堆疊、抽屜、對齊、交換)幾乎全部滿分。這支持了論文的核心主張:讓經驗「保持視覺化、保持有空間根據」,比壓成文字有效得多;而且不需要昂貴的老師模型。

## 做不到的地方

作者在結論裡誠實點名一個主要限制:

- **把桌面 3D 操作投影成 2.5D 視覺先驗是有侷限的**。目前的做法把 3D 空間簡化成 2.5D 地圖(水平面引導 ＋ 分開處理垂直軸),要擴展到**高度遮擋、第一人稱視角的真實 3D 機器人**,仍是關鍵的未來工作——也就是說,這套在格點世界與桌面操作上很強,搬到更複雜的真實 3D 場景還沒驗證。
- 訓練時用到了模擬器的「特權內部狀態」來建地圖(部署時只看畫面),這在沒有乾淨模擬器狀態的真實環境裡如何取得,並未解決。

## 怎麼看這件事

**為什麼值得在意?** 這篇挑戰了一個被廣泛採用、卻沒被認真質疑的習慣:智能體的記憶與獎勵都用文字。它用很乾淨的對照(同一個小模型,加不加這套記憶,0.09 → 0.93)說明:對空間任務,「讓記憶保持視覺化」不是錦上添花,而是關鍵;而且能擺脫對昂貴老師模型的依賴。

**哪裡該保留懷疑?** 這是螞蟻集團主導的預印本,亮眼成績主要在格點謎題與桌面操作這類較受控的環境;作者自己也承認最弱環節是 3D 投影簡化,搬到高遮擋的真實機器人還沒做。「贏過 GPT-5」是在這些特定空間測試上,不代表通用能力更強。

**怎麼理解這個研究方向?** 智能體記憶正從「文字日記」轉向「與任務模態對齊的表徵」——空間任務就用空間地圖。這篇的價值在於把「模態對齊的記憶 ＋ 自我演化的密集獎勵」做成一個自洽閉環,並用小模型打敗大模型來凸顯:有時候瓶頸不在模型大小,而在你用什麼形式存經驗、給回饋。
