# 不必砸上億張圖文配對：用一組「參照座標」把現成的圖像與文字模型黏起來

> 原始論文：Learning Relative Representations for Fine-Grained Multimodal Alignment with Limited Data
> 作者·單位：Shiwon Kim、Yu Rang Park（韓國延世大學）
> arXiv：2605.16834v1 ・ 分類：cs.CV

一句話說重點：像 CLIP 那種能把圖片和文字對應起來的 AI，要靠上億組圖文配對訓練，醫療、生物等資料稀少的領域根本做不到；這篇提出 PAL，不重新訓練、不加笨重投影層，只學一小組「參照座標」，用「每個圖塊/詞跟這些座標有多像」當作通用語言來對齊兩個現成模型，在分類、檢索、分割上都明顯勝過同類方法。

---

## 背景：把圖片和文字「對齊」很強大，但代價高到一般領域用不起

像 **CLIP**、**ALIGN** 這類多模態基礎模型很厲害——它們把圖像編碼器和文字編碼器一起訓練，學出一個共享的語意空間，讓「一張貓的照片」和「貓」這個詞在空間裡靠得很近。這就能做零樣本分類（不用為新類別重訓就能辨識）、跨模態檢索（用文字找圖、用圖找文字）等。

但這個成功代價極高：通常要**上億組圖文配對**和龐大算力。在醫療、生物這種**配對資料稀少**的領域，根本複製不來。

於是有人改走「事後對齊」（post-hoc alignment）這條更務實的路：不從零訓練多模態模型，而是**保留各自獨立預訓練好的單模態模型（凍結不動），只學一個輕量模組把它們的表徵對齊**。背後的觀察是——訓練良好的模型，即使架構、目標、模態不同，內部表徵結構往往會「殊途同歸」。但問題是：多數事後對齊方法仍需要數百萬到數千萬組配對，而且**只對齊「整張圖 vs 整句話」的全域表徵**，忽略了「圖裡某個小區塊」對應「句中某個詞」這種**細粒度**的對應關係——這會拖累需要精細跨模態匹配的任務（如圖像分割）。

## 怎麼做：用「跟參照點有多像」當作兩個模型都聽得懂的通用語言

研究者提出 **PAL**（projection-free anchor learning，免投影的錨點學習）。核心巧思是用「相對表徵」（relative representation）取代「直接投影」：

不直接把圖像特徵硬投影到文字空間（那要學笨重的投影層），而是在每個模態空間裡各設一組**可學習的「錨點」**（anchors，可理解為一組參照座標／路標）。然後把每個圖塊、每個詞，都改用「它跟這組錨點分別有多像」這串相似度來描述。關鍵在於：**只要訓練讓「配對的圖文」對這些錨點呈現一致的相似度模式**，兩個原本各說各話的模型，就透過「相對於同一組參照點的關係」對齊起來了——錨點本身分模態各設、不共用，扮演各自空間裡的參照點。

之所以叫「免投影」，是因為它**只學這一小組錨點**，不需要笨重的投影層，非常輕量、省參數。最後用一個「跨注意力池化」（cross-attention pooling，CAP）把這些 token 層級的相似度聚合成一個彙整表徵，再用對稱的對比學習目標做最終對齊。

![論文 Figure 2：PAL 方法總覽。(a) token 層級相對表徵——凍結的圖塊/詞嵌入 Z_m 與一組可學習錨點 A_m 算相似度，得到「token 對錨點」的相似度矩陣（藍色＝凍結不動，紅色虛線＝可學習）；(b) 跨注意力池化（CAP）——對每個錨點在 token 維度做 softmax 加權彙整成 pooled 表徵 p_m，L2 正規化後用對比學習做跨模態對齊。](assets/articles/2605.16834v1-fig1.webp)

這張圖把方法拆成兩半。左邊 **(a) Token-level relative representations**：輸入經凍結的編碼器 `f_m` 得到一串 token 嵌入 `Z_m`（藍色方塊，代表「凍結不動」）；另設一組可學習錨點 `A_m`（紅色虛線圈，代表「可學習」）。每個 token 跟每個錨點算餘弦相似度——注意中間那塊「Absolute representation space」裡的箭頭，就是「某個 token 對各錨點有多像」的相對關係，這就是兩個模型共通的「通用語言」。右邊 **(b) Anchor-wise token pooling（CAP）**：把所有 token 對所有錨點（Anchor 1…Anchor K）的相似度排成矩陣，對每個錨點在 token 維度做 `Softmax` 加權求和（Σ），彙整成一個 K 維的 pooled 相對表徵 `p_m`，再 `L2 normalize`，最後送進 `Contrastive learning`（對比學習）做跨模態對齊。整個流程沒有笨重的投影層，要學的只有那組錨點。

## 結果：低資料下，三類任務都明顯領先

研究者在三類任務上評測——零樣本分類（STL10、CIFAR100、Caltech101、DTD、EuroSAT 等）、跨模態檢索（Flickr30k、COCO）、零樣本分割（ADE20K、Pascal Context、VOC20）。結論是：在**有限配對資料**設定下，PAL **一致地、且以顯著幅度**勝過現有的事後對齊基準（如 STRUCTURE、SAIL、FA），尤其在**檢索與分割**上提升最大——而這兩類正是最需要「細粒度跨模態結構」的任務。論文也分析了錨點的「專化與重用」現象：不同錨點會自發地各司其職。這印證了作者的論點：低資料對齊不能只靠「整句 vs 整圖」的粗對齊，還要能組織細粒度的跨模態結構。

## 做不到的地方

論文很坦白地列出限制：錨點的「專化、語意重用」是**從對齊目標中隱性浮現的，並非明確設計強制的**——還沒有機制能直接鼓勵錨點解耦或可控分工，這限制了可解釋性。此外，實驗**聚焦在低資料情境**（這正是事後對齊最有實用價值的場景）；雖然加更多配對資料時 PAL 仍持續進步，但作者**沒有在「數百萬規模」上驗證**，錨點式對齊在大規模配對資料下的行為仍是未來工作。作者也在「更廣影響」中提醒：對齊後的表徵會**繼承底層預訓練模型與資料集的偏見**，用於高風險領域前需審慎評估。

## 怎麼看這件事

**為什麼值得在意？** 「把圖像和文字對齊」是多模態 AI 的基石，但門檻被上億配對資料卡死，讓醫療、生物這些最需要 AI、卻最缺配對資料的領域望而卻步。PAL 用「重用現成模型 + 只學一小組參照點」把資料與算力需求大幅降低，這在資源受限領域有實際落地意義。

**哪裡該保留懷疑？** 「明顯勝過」是在低資料、特定基準與對照方法下成立的；作者自己明說沒在大規模資料上驗證，也沒明確強制錨點分工（是「碰巧長出來」的）。對齊結果還會繼承底層模型偏見——直接搬到醫療等高風險場景前必須謹慎評估。

**怎麼理解這個研究方向？** 這呼應一個越來越主流的觀點：與其每次都從零訓練巨型多模態模型，不如**善用已經訓練好的單模態模型，再用輕量方式把它們「黏」起來**。用「相對於共同參照點的關係」當跨模態通用語言，是一個優雅且省資源的黏合思路——這條「模組化、低資料、重用基礎模型」的路線，正是讓多模態 AI 走進資源受限領域的關鍵方向之一。
