## 目前政策（可逐條改值或敘述）

1. **範圍**：當天爬到的論文**全部**處理，含 `new` 與 `cross/replace`，
   **不篩選、不分級、不寫短版**。〔現狀，user 明確要求〕
2. **語言/讀者**：繁體中文，寫給**非研究者**看的科普。
3. **標題**：白話、吸睛、為一般人重寫，**不是論文原名**。
   〔旋鈕：想更收斂或更聳動，在這行寫清楚〕
4. **長度/節奏**：對齊參考文 `data/articles/2605.15217v1.md`（中等長度）。
   〔旋鈕：想整體更短/更長，改這行；例如「比參考文短三成」〕
5. **文章結構**：一句話重點 → 背景/問題 → 怎麼做 → 結果 → 做不到的地方
   → 「想自己判斷這篇可不可信？」表 → 「怎麼看這件事」。
   〔旋鈕：要砍掉或加哪一段，在這行列出〕
6. **圖**：一篇配一張**論文裡真的圖**（架構圖或關鍵結果圖，不要公式/表/logo），
   caption 必須與圖一致；沒有好圖就**如實說明、不放圖、不捏造**。
7. **語氣**：具體、誠實講限制、不吹捧；`**粗體**` 少用（網站只有一種粗細、無顏色）。
8. **無法處理的論文**（arXiv 取不到 PDF）：跳過並在回報中列出，**絕不捏造**。
   每天約有數篇屬此類，屬正常。
9. **部署**：推 `main` → GitHub Pages；repo 根目錄一定要有 `.nojekyll`；
   **永不**重建 `_config.yml`、**永不**啟用 `.github/workflows/run.yml`。
